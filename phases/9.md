# Phase 9: Python Stubs, Type System & Public API Hardening

## Goal
Deliver production-quality Python type stubs (`.pyi` files) for all exported types, enforce the minimal clean public API surface, add a `py.typed` marker, and verify the stub types match the actual runtime behavior. This phase also finalizes the Python package structure.

## Scope
- Complete `.pyi` stub files for every exported symbol
- `py.typed` PEP 561 marker
- `__all__` declarations in each module
- Public API audit: remove any accidentally exposed internals
- `overload` signatures for methods that return different types based on args
- Generic types for `QuerySet[Model]`, `Manager[Model]`
- Async return type annotations (`Awaitable`, `AsyncIterator`, `AsyncContextManager`)
- Final package layout: `ormpi/__init__.pyi`, `ormpi/fields.pyi`, etc.

## Package Layout

```
ormpi/
  __init__.py          # re-exports from _core (the .so extension)
  __init__.pyi         # top-level stub
  py.typed             # PEP 561 marker
  fields.pyi           # Field class stubs
  models.pyi           # Model, Manager stubs
  query.pyi            # QuerySet, Q stubs
  db/
    __init__.pyi       # connections, connection
  transaction.pyi      # begin, rollback, atomic, Transaction
  exceptions.pyi       # all exception classes
  aggregates.pyi       # Count, Sum, Avg, Max, Min
  _core.pyi            # raw extension module stubs (internal, not for users)
```

## API Hardening Rules

1. **No `_` prefix internals exported**: `__all__` in each `__init__.py` lists only public names.
2. **No sea-query types leak to Python**: `ColumnDef`, `SelectStatement`, etc. are strictly internal.
3. **No `OrmpiPool` exposed**: connection management is internal.
4. **No `ModelRegistry` exposed**: model registration is automatic, not manual.
5. **No `QueryState` exposed**: users interact only with `QuerySet` methods.
6. **Exception hierarchy clean**:
   ```
   OrmpiError
     DatabaseError
       IntegrityError
       OperationalError
     ValidationError
       FieldError
     TransactionError
     MigrationError
     DoesNotExist        (also on Model subclasses: Article.DoesNotExist)
     MultipleObjectsReturned
   ```

## Deliverables
1. All `.pyi` files complete and passing `mypy --strict`.
2. `py.typed` marker present.
3. `pyright` / `pylance` shows no errors on example usage.
4. `__all__` enforced — `from ormpi import *` gives exactly the public API.
5. Generic `QuerySet[M]` inferred correctly through method chains.
