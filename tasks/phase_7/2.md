# Task 7.2 — Migration Operations, File Format & Executor

## Objective
Implement all migration operations with their `state_forwards`/`state_backwards` and `database_forwards`/`database_backwards` methods. Implement TOML-based migration file serialization/deserialization and the `MigrationExecutor` that applies and reverses migrations in a transaction.

```rust
pub trait MigrationOperation: Send + Sync + std::fmt::Debug {
    fn name(&self) -> &str;
    fn operation_type(&self) -> OpType;
    fn primary_identifier(&self) -> String;

    fn state_forwards(&self, state: &mut ProjectState);

    fn database_forwards(&self, backend: &QueryBackend) -> Vec<String>;
```

## CreateModel Operation

```rust
#[derive(Debug)]
pub struct CreateModelOp {
    pub app_label: String,
    pub name: String,
    pub fields: Vec<FieldDef>,
    pub options: ModelOptions,
}

impl MigrationOperation for CreateModelOp {
    fn name(&self) -> &str { "CreateModel" }
    fn operation_type(&self) -> OpType { OpType::CreateModel }
    fn primary_identifier(&self) -> String { self.name.clone() }

    fn state_forwards(&self, state: &mut ProjectState) {
        let key = format!("{}.{}", self.app_label, self.name);
        let model_state = ModelState {
            app_label: self.app_label.clone(),
            name: self.name.clone(),
            fields: self.fields.iter().map(|f| (f.attname.clone(), FieldState::from_field(f))).collect(),
            options: self.options.clone(),
        };
        state.models.insert(key, model_state);
    }

    fn state_backwards(&self, state: &mut ProjectState) {
        let key = format!("{}.{}", self.app_label, self.name);
        state.models.remove(&key);
    }

    fn database_forwards(&self, backend: &QueryBackend) -> Vec<String> {
        // Build a temporary ModelDef to reuse model_to_ddl
        let temp_def = build_temp_model_def(&self.app_label, &self.name, &self.fields, &self.options);
        let ddl = model_to_ddl(&temp_def, *backend);
        let mut sqls = vec![ddl.create_table];
        sqls.extend(ddl.create_indexes);
        sqls.extend(ddl.create_m2m_tables);
        sqls
    }

    fn database_backwards(&self, backend: &QueryBackend) -> Vec<String> {
        let table_name = self.options.db_table.clone()
            .unwrap_or_else(|| ModelDef::default_table_name(&self.app_label, &self.name));
        let stmt = sea_query::Table::drop()
            .table(sea_query::Alias::new(&table_name))
            .if_exists()
            .to_owned();
        vec![backend.build_table_drop(&stmt)]
    }

    fn describe(&self) -> String { format!("Create model {}", self.name) }
}
```

## AddField / RemoveField / AlterField

```rust
#[derive(Debug)]
pub struct AddFieldOp {
    pub model: String, pub name: String, pub field: FieldDef,
}

impl MigrationOperation for AddFieldOp {
    fn database_forwards(&self, backend: &QueryBackend) -> Vec<String> {
        let col = self.field.to_column_def().expect("AddField: not a column field");
        let stmt = sea_query::Table::alter()
            .table(sea_query::Alias::new(&model_table(&self.model)))
            .add_column(col)
            .to_owned();
        vec![backend.build_table_alter(&stmt)]
    }

    fn database_backwards(&self, backend: &QueryBackend) -> Vec<String> {
        // For SQLite: full table rebuild needed (handled in executor)
        let stmt = sea_query::Table::alter()
            .table(sea_query::Alias::new(&model_table(&self.model)))
            .drop_column(sea_query::Alias::new(&self.field.column_name()))
            .to_owned();
        vec![backend.build_table_alter(&stmt)]
    }
    // ... state_forwards, state_backwards
}
```

## TOML Migration File Format

```rust
// ormpi-core/src/migration/file.rs
use serde::{Deserialize, Serialize};

#[derive(Debug, Serialize, Deserialize)]
pub struct MigrationFile {
    pub migration: MigrationMeta,
    pub operations: Vec<OperationRecord>,
}

#[derive(Debug, Serialize, Deserialize)]
pub struct MigrationMeta {
    pub name: String,
    pub dependencies: Vec<String>,   // ["0001_initial"] or ["other_app.0001_initial"]
    pub replaces: Vec<String>,       // for squashed migrations
}

#[derive(Debug, Serialize, Deserialize)]
pub struct OperationRecord {
    pub r#type: String,
    // Flatten all operation-specific fields
    #[serde(flatten)]
    pub data: toml::Value,
}

impl MigrationFile {
    pub fn write_to_file(&self, path: &Path) -> crate::Result<()> {
        let content = toml::to_string_pretty(self)?;
        std::fs::write(path, content)?;
        Ok(())
    }

    pub fn read_from_file(path: &Path) -> crate::Result<Self> {
        let content = std::fs::read_to_string(path)?;
        let file: MigrationFile = toml::from_str(&content)?;
        Ok(file)
    }

    pub fn to_operations(&self) -> crate::Result<Vec<Box<dyn MigrationOperation>>> {
        self.operations.iter().map(|record| {
            deserialize_operation(&record.r#type, &record.data)
        }).collect()
    }
}
```

## MigrationExecutor

```rust
// ormpi-core/src/migration/executor.rs
pub struct MigrationExecutor {
    pub recorder: MigrationRecorder,
    pub graph: MigrationGraph,
    pub pool: OrmpiPool,
    pub backend: QueryBackend,
}

impl MigrationExecutor {
    pub async fn migrate(
        &self,
        target: Option<&str>,   // None = latest
        fake: bool,
    ) -> crate::Result<()> {
        let applied = self.recorder.applied().await?;
        let to_apply = self.graph.migrations_to_apply(target, &applied);

        for migration_name in to_apply {
            println!("  Applying {}... ", migration_name);
            let start = std::time::Instant::now();

            if !fake {
                self.apply_migration(migration_name).await?;
            }

            self.recorder.record_applied("default", migration_name).await?;
            println!("OK ({:.3}s)", start.elapsed().as_secs_f64());
        }
        Ok(())
    }

    async fn apply_migration(&self, name: &str) -> crate::Result<()> {
        let migration = self.graph.get(name).unwrap();
        let ops = migration.to_operations()?;

        // Each migration runs in a single transaction
        match &self.pool {
            OrmpiPool::Sqlite(p) => {
                let mut txn = p.begin().await?;
                for op in &ops {
                    let sqls = op.database_forwards(&self.backend);
                    for sql in sqls {
                        sqlx::query(&sql).execute(&mut *txn).await
                            .map_err(|e| OrmpiError::MigrationError(
                                format!("Migration {} failed: {}\nSQL: {}", name, e, sql)
                            ))?;
                    }
                }
                txn.commit().await?;
            }
            // ... MySQL, Postgres variants
        }
        Ok(())
    }

    pub async fn rollback_to(&self, target: &str, fake: bool) -> crate::Result<()> {
        let applied = self.recorder.applied().await?;
        let to_unapply = self.graph.migrations_to_unapply(target, &applied);

        for migration_name in to_unapply.iter().rev() {
            println!("  Unapplying {}... ", migration_name);
            if !fake {
                self.unapply_migration(migration_name).await?;
            }
            self.recorder.record_unapplied("default", migration_name).await?;
            println!("OK");
        }
        Ok(())
    }
}
```

## SQLite ALTER TABLE Workaround

For operations that SQLite doesn't support (DROP COLUMN before 3.35, MODIFY COLUMN):

```rust
pub async fn sqlite_table_rebuild(
    conn: &mut sqlx::SqliteConnection,
    old_model: &ModelState,
    new_model: &ModelState,
    backend: QueryBackend,
) -> crate::Result<()> {
    let old_table = &old_model.table_name();
    let temp_table = format!("{}_new", old_table);

    // 1. Create new table with desired schema
    let new_create = build_create_for_state(new_model, backend, &temp_table);
    sqlx::query(&new_create).execute(conn).await?;

    // 2. Copy data (only common columns)
    let common_cols: Vec<String> = old_model.fields.keys()
        .filter(|k| new_model.fields.contains_key(*k))
        .cloned().collect();
    let cols_csv = common_cols.join(", ");
    let copy_sql = format!("INSERT INTO {} ({}) SELECT {} FROM {}", temp_table, cols_csv, cols_csv, old_table);
    sqlx::query(&copy_sql).execute(conn).await?;

    // 3. Drop old, rename new
    sqlx::query(&format!("DROP TABLE {}", old_table)).execute(conn).await?;
    sqlx::query(&format!("ALTER TABLE {} RENAME TO {}", temp_table, old_table)).execute(conn).await?;

    Ok(())
}
```

## Acceptance Criteria
- [ ] `CreateModelOp.database_forwards()` produces valid CREATE TABLE SQL
- [ ] `CreateModelOp.database_backwards()` produces DROP TABLE SQL
- [ ] `AddFieldOp.database_forwards()` produces ALTER TABLE ADD COLUMN
- [ ] `RemoveFieldOp.database_backwards()` rebuilds table on SQLite
- [ ] Migration file roundtrips: write → read → same operations
- [ ] `MigrationExecutor.migrate()` applies in topological order
- [ ] Failed migration triggers full rollback (table state unchanged)
- [ ] `--fake` marks migrations as applied without running SQL
- [ ] `rollback_to("zero")` reverses all migrations
