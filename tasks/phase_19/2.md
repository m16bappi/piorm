# Task 19.2 — Fix F() Expressions in `update()` (Type Mismatch in SQL)

## Failing Tests

```
TestUpdateFExpressions::test_f_add
TestUpdateFExpressions::test_f_subtract
TestUpdateFExpressions::test_f_multiply
TestUpdateFExpressions::test_f_divide
TestUpdateFExpressions::test_f_applied_to_all_rows
TestUpdateFExpressions::test_f_chained_arithmetic
TestUpdateFExpressions::test_f_applied_to_filtered_subset
TestUpdateEdgeCases::test_f_on_zero_value
TestQuerySetUpdate::test_update_with_f_expression   (test_write.py)
TestQuerySetUpdate::test_update_with_f_multiplication (test_write.py)
```

Error:
```
RuntimeError: Database error: error occurred while decoding column 3:
mismatched types; Rust type `Option<i64>` (as SQL type `INTEGER`) is not
compatible with SQL type `TEXT`
```

## Root Cause

When `update(age=F("age") + 5)` is called, `F("age") + 5` creates a Python `_FExpr`
object (defined in `ormpi/expr.py`). In the `update()` Rust method, `py_to_ormpi_value`
is called on the `_FExpr` object. Since `_FExpr` is a pure-Python class (not an int/str),
it falls through to the JSON fallback:

```python
json_str = obj.str()?.extract::<String>()?;   // → "(<F('age')> + 5)"
Ok(OrmpiValue::Text(json_str))
```

The SQL becomes:
```sql
UPDATE authors SET age = '(<F(''age'')> + 5)' WHERE ...
```

SQLite stores this as TEXT, but the `age` column is INTEGER. The next `SELECT` decodes the
value and hits the type mismatch.

## Fix — Detect `F` and `_FExpr` in `py_to_ormpi_value` and Build SQL Expressions

### Step 1 — Add `FExpr` variant to `OrmpiValue`

**File:** `ormpi-core/src/value.rs`

```rust
pub enum OrmpiValue {
    // ... existing variants ...
    FExpr(Box<FExprNode>),    // ← NEW: represents a field-reference expression
}

/// A recursive F() expression tree.
#[derive(Debug, Clone)]
pub enum FExprNode {
    Field(String),                              // F("age")
    BinOp {
        lhs: Box<FExprNode>,
        op:  FExprOp,
        rhs: Box<FExprNode>,
    },
    Literal(Box<OrmpiValue>),                   // constant operand like 5
}

#[derive(Debug, Clone)]
pub enum FExprOp { Add, Sub, Mul, Div, Mod }
```

### Step 2 — Convert Python `F`/`_FExpr` → `OrmpiValue::FExpr`

**File:** `ormpi-py/src/model/instance.rs`

Add conversion after the existing type checks in `py_to_ormpi_value`:

```rust
// Detect F("field") — has .name attribute, no .op
if let Ok(name) = obj.getattr("name") {
    if let Ok(field_name) = name.extract::<String>() {
        // Check it's actually an F object (has name but no lhs/rhs)
        if obj.getattr("lhs").is_err() {
            return Ok(OrmpiValue::FExpr(Box::new(FExprNode::Field(field_name))));
        }
    }
}

// Detect _FExpr — has .lhs, .op, .rhs attributes
if let (Ok(lhs_obj), Ok(op_str), Ok(rhs_obj)) = (
    obj.getattr("lhs"),
    obj.getattr("op"),
    obj.getattr("rhs"),
) {
    let lhs = py_to_ormpi_value(&lhs_obj)?;
    let rhs = py_to_ormpi_value(&rhs_obj)?;
    let op_s: String = op_str.extract()?;
    let op = match op_s.as_str() {
        "+" => FExprOp::Add,
        "-" => FExprOp::Sub,
        "*" => FExprOp::Mul,
        "/" => FExprOp::Div,
        "%" => FExprOp::Mod,
        _ => return Err(pyo3::exceptions::PyValueError::new_err(
            format!("Unknown F() operator: {}", op_s)
        )),
    };
    let node = FExprNode::BinOp {
        lhs: Box::new(lhs.into_fexpr_node()?),
        op,
        rhs: Box::new(rhs.into_fexpr_node()?),
    };
    return Ok(OrmpiValue::FExpr(Box::new(node)));
}
```

Add helper `OrmpiValue::into_fexpr_node()` to convert `FExpr` / `Int` / `Float` /
`Text` into `FExprNode`.

### Step 3 — Build sea-query `Expr` from `FExprNode` in the UPDATE handler

**File:** `ormpi-core/src/query/evaluate.rs`

When building the SET clause of an UPDATE, detect `OrmpiValue::FExpr` and build a
sea-query arithmetic expression:

```rust
fn fexpr_to_sea_expr(node: &FExprNode, table: &str) -> sea_query::SimpleExpr {
    match node {
        FExprNode::Field(name) => {
            Expr::col((Alias::new(table), Alias::new(name)))
        }
        FExprNode::Literal(val) => {
            Expr::val(val.to_sea_value())
        }
        FExprNode::BinOp { lhs, op, rhs } => {
            let l = fexpr_to_sea_expr(lhs, table);
            let r = fexpr_to_sea_expr(rhs, table);
            match op {
                FExprOp::Add => l.add(r),
                FExprOp::Sub => l.sub(r),
                FExprOp::Mul => l.mul(r),
                FExprOp::Div => l.div(r),
                FExprOp::Mod => l.modulo(r),
            }
        }
    }
}
```

In the UPDATE SET clause builder:
```rust
for (field_name, value) in updates {
    let col = resolve_column(&[field_name.clone()], model_def);
    if let OrmpiValue::FExpr(node) = &value {
        stmt.value(Alias::new(&col), fexpr_to_sea_expr(node, &model_def.table_name));
    } else {
        stmt.value(Alias::new(&col), Expr::val(value.to_sea_value()));
    }
}
```
