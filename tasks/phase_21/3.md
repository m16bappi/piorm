### The `FromStr` impl for `Lookup`

```rust
impl std::str::FromStr for Lookup {
    type Err = ();

    fn from_str(s: &str) -> Result<Self, Self::Err> {
        match s {
            "exact" => Ok(Self::Exact),
            "iexact" => Ok(Self::IExact),
            // ... all variants ...
            _ => Err(()),
        }
    }
}
```

Then update callers from `Lookup::from_str(s)` to `s.parse::<Lookup>()`.
