# Task 21.5 — Add `#![deny(missing_docs)]` and Document Public API

## Severity

**MEDIUM** — Undocumented public API makes the library hard to use correctly.

## Problem

`ormpi-core/src/lib.rs` has no `#![deny(missing_docs)]` and no module-level documentation.
Many public functions, structs, and enums lack `///` doc comments.

Undocumented items include:
- All `bind.rs` public functions
- All `row.rs` public converters
- Most `query/evaluate.rs` public functions
- `QueryBackend` methods in `backend.rs`
- `OrmpiPool` methods
- `FieldDef`, `FieldType`, and related types
- Migration operations trait and structs

## Fix

### Step 1 — Add crate-level lint and documentation

```rust
// ormpi-core/src/lib.rs
#![deny(missing_docs)]

//! ormpi-core: A Django-inspired ORM runtime for Rust.
//!
//! Provides database abstraction, query building, model definition, and
//! migration infrastructure for the ormpi project.
```

### Step 2 — Add `///` doc comments to all public items

Follow the convention:
- `///` comments explain **what** and **how** for public APIs
- `//` comments explain **why** (safety, workarounds, design rationale)
- Every `TODO` needs a linked issue: `// TODO(#42): ...`

Priority order for documentation:
1. `error.rs` — public error type
2. `value.rs` — `OrmpiValue` enum and conversions
3. `backend.rs` — `DatabaseBackend`, `QueryBackend`
4. `pool.rs` — `OrmpiPool`
5. `fields/` — `FieldDef`, `FieldType`, `DefaultValue`
6. `model/def.rs` — `ModelDef`
7. `model/registry.rs` — `ModelRegistry`
8. `query/` — `QueryState`, `evaluate`, `filter`
9. `migration/` — `MigrationOperation` trait, `AutoDetector`, `MigrationGraph`
10. `bind.rs`, `row.rs`, `executor.rs`, `transaction.rs`

### Step 3 — Add doc examples for key types

```rust
/// A database column value, backend-agnostic.
///
/// # Examples
///
/// ```
/// use ormpi_core::value::OrmpiValue;
///
/// let val = OrmpiValue::Int(42);
/// assert_eq!(val.to_sea_value(), sea_query::Value::BigInt(Some(42)));
/// ```
#[derive(Debug, Clone, PartialEq)]
pub enum OrmpiValue { ... }
```
