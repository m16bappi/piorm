# Task 6.1 — Transaction Struct & begin/commit/rollback

## Objective
Implement the `OrmpiTransaction` Rust struct wrapping sqlx transactions, and the Python-facing `begin()`, `commit()`, and `rollback()` functions. Handle the lifetime/ownership challenge of holding an `sqlx::Transaction` in a PyO3 class.

## Location
`ormpi-core/src/transaction.rs`
`ormpi-py/src/transaction.rs`

## OrmpiTransaction (Rust)

The key challenge: `sqlx::Transaction<'_, DB>` has a lifetime tied to the pool connection. To hold it in a PyO3 class (which requires `'static`), we use `Box::pin` with an owned connection:

```rust
// ormpi-core/src/transaction.rs
use sqlx::Transaction;
use std::pin::Pin;

pub enum TransactionHandle {
    Sqlite(Pin<Box<Transaction<'static, sqlx::Sqlite>>>),
    Mysql(Pin<Box<Transaction<'static, sqlx::MySql>>>),
    Postgres(Pin<Box<Transaction<'static, sqlx::Postgres>>>),
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub enum TransactionState { Open, Committed, RolledBack }

pub struct OrmpiTransaction {
    pub handle: TransactionHandle,
    pub db_alias: String,
    pub depth: u32,          // 0 = real txn, >0 = nested savepoint
    pub savepoint_name: Option<String>,
    pub state: TransactionState,
    pub on_commit_callbacks: Vec<PyObject>,
}

impl OrmpiTransaction {
    pub async fn begin(pool: &OrmpiPool, alias: &str) -> crate::Result<Self> {
        let handle = match pool {
            OrmpiPool::Sqlite(p) => {
                let txn = p.begin().await?;
                // SAFETY: We ensure the pool lives as long as the transaction
                let txn: Transaction<'static, sqlx::Sqlite> = unsafe {
                    std::mem::transmute(txn)
                };
                TransactionHandle::Sqlite(Box::pin(txn))
            }
            OrmpiPool::Mysql(p) => { /* similar */ }
            OrmpiPool::Postgres(p) => { /* similar */ }
        };

        Ok(OrmpiTransaction {
            handle,
            db_alias: alias.to_string(),
            depth: 0,
            savepoint_name: None,
            state: TransactionState::Open,
            on_commit_callbacks: Vec::new(),
        })
    }

    pub async fn commit(&mut self) -> crate::Result<()> {
        if self.state != TransactionState::Open {
            return Err(OrmpiError::TransactionError("Transaction is not open".into()));
        }
        match &mut self.handle {
            TransactionHandle::Sqlite(t)   => t.as_mut().commit().await?,
            TransactionHandle::Mysql(t)    => t.as_mut().commit().await?,
            TransactionHandle::Postgres(t) => t.as_mut().commit().await?,
        }
        self.state = TransactionState::Committed;

        // Fire on_commit callbacks
        Python::with_gil(|py| {
            for cb in &self.on_commit_callbacks {
                if let Err(e) = cb.call0(py) {
                    tracing::warn!("on_commit callback failed: {:?}", e);
                }
            }
        });
        self.on_commit_callbacks.clear();
        Ok(())
    }

    pub async fn rollback(&mut self) -> crate::Result<()> {
        if self.state != TransactionState::Open {
            return Err(OrmpiError::TransactionError("Transaction is not open".into()));
        }
        match &mut self.handle {
            TransactionHandle::Sqlite(t)   => t.as_mut().rollback().await?,
            TransactionHandle::Mysql(t)    => t.as_mut().rollback().await?,
            TransactionHandle::Postgres(t) => t.as_mut().rollback().await?,
        }
        self.state = TransactionState::RolledBack;
        self.on_commit_callbacks.clear();
        Ok(())
    }

    pub async fn execute_raw(&mut self, sql: &str) -> crate::Result<()> {
        match &mut self.handle {
            TransactionHandle::Sqlite(t)   => { sqlx::query(sql).execute(t.as_mut()).await?; }
            TransactionHandle::Mysql(t)    => { sqlx::query(sql).execute(t.as_mut()).await?; }
            TransactionHandle::Postgres(t) => { sqlx::query(sql).execute(t.as_mut()).await?; }
        }
        Ok(())
    }
}
```

## PyTransaction (PyO3)

```rust
// ormpi-py/src/transaction.rs
#[pyclass(name = "Transaction", unsendable)]
pub struct PyTransaction {
    inner: Option<OrmpiTransaction>,  // Option to allow "moved out" state
}

#[pymethods]
impl PyTransaction {
    fn commit<'py>(&mut self, py: Python<'py>) -> PyResult<&'py PyAny> {
        let mut txn = self.inner.take()
            .ok_or_else(|| PyRuntimeError::new_err("Transaction already consumed"))?;

        pyo3_async_runtimes::tokio::future_into_py(py, async move {
            txn.commit().await.map_err(PyErr::from)?;
            Ok(())
        })
    }

    fn rollback<'py>(&mut self, py: Python<'py>) -> PyResult<&'py PyAny> {
        let mut txn = self.inner.take()
            .ok_or_else(|| PyRuntimeError::new_err("Transaction already consumed"))?;

        pyo3_async_runtimes::tokio::future_into_py(py, async move {
            txn.rollback().await.map_err(PyErr::from)?;
            Ok(())
        })
    }

    fn on_commit(&mut self, py: Python<'_>, callback: PyObject) -> PyResult<()> {
        if let Some(ref mut txn) = self.inner {
            if txn.state != TransactionState::Open {
                return Err(PyRuntimeError::new_err("Transaction is not open"));
            }
            txn.on_commit_callbacks.push(callback);
            Ok(())
        } else {
            Err(PyRuntimeError::new_err("Transaction already consumed"))
        }
    }

    #[getter]
    fn is_open(&self) -> bool {
        self.inner.as_ref().map(|t| t.state == TransactionState::Open).unwrap_or(false)
    }

    fn __repr__(&self) -> String {
        match &self.inner {
            Some(t) => format!("<Transaction db='{}' state={:?}>", t.db_alias, t.state),
            None    => "<Transaction consumed>".to_string(),
        }
    }
}
```

## begin() Python Function

```rust
#[pyfunction]
fn begin<'py>(py: Python<'py>, using: Option<String>) -> PyResult<&'py PyAny> {
    let alias = using.unwrap_or_else(|| "default".to_string());

    pyo3_async_runtimes::tokio::future_into_py(py, async move {
        let registry = DatabaseRegistry::global().read().unwrap();
        let pool = registry.get_pool(&alias)?;
        let txn = OrmpiTransaction::begin(pool, &alias).await?;

        Python::with_gil(|py| {
            let py_txn = PyTransaction { inner: Some(txn) };
            Ok(Py::new(py, py_txn)?.into_py(py))
        })
    })
}
```

## rollback() Convenience Function

```rust
#[pyfunction]
fn rollback<'py>(py: Python<'py>, txn: &mut PyTransaction) -> PyResult<&'py PyAny> {
    txn.rollback(py)
}
```

## Acceptance Criteria
- [ ] `txn = await begin()` creates a real database transaction
- [ ] `await txn.commit()` commits and fires `on_commit` callbacks
- [ ] `await txn.rollback()` rolls back without firing callbacks
- [ ] `await txn.commit()` twice raises `TransactionError`
- [ ] `txn.on_commit(fn)` registers callback, called only on commit
- [ ] `on_commit` callbacks skipped on rollback
- [ ] `txn.is_open` property reflects state correctly
- [ ] `unsendable` prevents sending transaction across threads
- [ ] Transaction executes actual SQL on the correct database
