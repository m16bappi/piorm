# Task 2: `PiormPool` Execution Helpers — Eliminate Repeated Backend Dispatch

## Problem

The pattern below appears **10+ times** across `piorm-core/src/executor.rs` and `piorm-core/src/model/executor.rs`. Every call site must manually import `bind::*`, build arguments per-backend, and repeat the 3-arm match:

```rust
// Appears in model/executor.rs at lines 191-203, 267-280, 297-311, 328-341, 386-409
// and in executor.rs at lines 6-63 (various forms)
match pool {
    PiormPool::Sqlite(p) => {
        let args = sqlite_arguments(sea_vals.clone());
        sqlx::query_with(&sql, args).execute(p).await?.rows_affected() as usize
    }
    PiormPool::Mysql(p) => {
        let args = mysql_arguments(sea_vals.clone());
        sqlx::query_with(&sql, args).execute(p).await?.rows_affected() as usize
    }
    PiormPool::Postgres(p) => {
        let args = postgres_arguments(sea_vals);
        sqlx::query_with(&sql, args).execute(p).await?.rows_affected() as usize
    }
}
```

This violates DRY and means any future backend requires touching every call site.

## Fix

Add four methods to `PiormPool` in `pool.rs` that encapsulate backend dispatch + argument binding. All call sites in `executor.rs` and `model/executor.rs` then become single-line awaits.

### Step 1 — Add methods to `piorm-core/src/pool.rs`

Add the following after the `close()` method (after line 64):

```rust
use sea_query::Values;
use crate::bind::{mysql_arguments, postgres_arguments, sqlite_arguments};
use crate::row::{mysql_row_to_piorm, postgres_row_to_piorm, sqlite_row_to_piorm, PiormRow};

impl PiormPool {
    // ... existing methods ...

    /// Execute a DML/DDL statement and return the number of rows affected.
    pub async fn execute(&self, sql: &str, values: Values) -> crate::Result<u64> {
        match self {
            PiormPool::Sqlite(p) => Ok(sqlx::query_with(sql, sqlite_arguments(values))
                .execute(p).await?.rows_affected()),
            PiormPool::Mysql(p) => Ok(sqlx::query_with(sql, mysql_arguments(values))
                .execute(p).await?.rows_affected()),
            PiormPool::Postgres(p) => Ok(sqlx::query_with(sql, postgres_arguments(values))
                .execute(p).await?.rows_affected()),
        }
    }

    /// Execute a SELECT and return all rows as `PiormRow`.
    pub async fn fetch_all(&self, sql: &str, values: Values) -> crate::Result<Vec<PiormRow>> {
        match self {
            PiormPool::Sqlite(p) => sqlx::query_with(sql, sqlite_arguments(values))
                .fetch_all(p).await?
                .iter().map(sqlite_row_to_piorm).collect(),
            PiormPool::Mysql(p) => sqlx::query_with(sql, mysql_arguments(values))
                .fetch_all(p).await?
                .iter().map(mysql_row_to_piorm).collect(),
            PiormPool::Postgres(p) => sqlx::query_with(sql, postgres_arguments(values))
                .fetch_all(p).await?
                .iter().map(postgres_row_to_piorm).collect(),
        }
    }

    /// Execute a SELECT and return the first row. Propagates `RowNotFound` as-is.
    pub async fn fetch_one(&self, sql: &str, values: Values) -> crate::Result<PiormRow> {
        match self {
            PiormPool::Sqlite(p) => sqlite_row_to_piorm(
                &sqlx::query_with(sql, sqlite_arguments(values)).fetch_one(p).await?),
            PiormPool::Mysql(p) => mysql_row_to_piorm(
                &sqlx::query_with(sql, mysql_arguments(values)).fetch_one(p).await?),
            PiormPool::Postgres(p) => postgres_row_to_piorm(
                &sqlx::query_with(sql, postgres_arguments(values)).fetch_one(p).await?),
        }
    }

    /// Execute a SELECT and return the first row or `None`.
    pub async fn fetch_optional(&self, sql: &str, values: Values) -> crate::Result<Option<PiormRow>> {
        match self {
            PiormPool::Sqlite(p) => sqlx::query_with(sql, sqlite_arguments(values))
                .fetch_optional(p).await?
                .map(|r| sqlite_row_to_piorm(&r))
                .transpose(),
            PiormPool::Mysql(p) => sqlx::query_with(sql, mysql_arguments(values))
                .fetch_optional(p).await?
                .map(|r| mysql_row_to_piorm(&r))
                .transpose(),
            PiormPool::Postgres(p) => sqlx::query_with(sql, postgres_arguments(values))
                .fetch_optional(p).await?
                .map(|r| postgres_row_to_piorm(&r))
                .transpose(),
        }
    }
}
```

### Step 2 — Simplify `piorm-core/src/executor.rs`

Replace the entire file with:

```rust
use crate::pool::PiormPool;
use crate::value::PiormValue;
use sea_query::Values;

/// Execute a raw SQL statement that doesn't return rows (DDL / DML).
pub async fn execute_sql(pool: &PiormPool, sql: &str) -> crate::Result<u64> {
    pool.execute(sql, Values(vec![])).await
}

/// Execute a raw SELECT with optional positional params and return all rows as `PiormRow`.
pub async fn fetch_all_raw(
    pool: &PiormPool,
    sql: &str,
    params: &[PiormValue],
) -> crate::Result<Vec<crate::row::PiormRow>> {
    let values = Values(params.iter().map(|v| v.to_sea_value()).collect());
    pool.fetch_all(sql, values).await
}
```

The old `fetch_one_raw`, `fetch_row_sqlite/mysql/postgres`, and `row_to_json_*` helpers move to `row.rs` or are removed (see Task 4).

### Step 3 — Simplify `piorm-core/src/model/executor.rs`

Replace every inline backend-dispatch block. Examples:

