# Task 4 — Closure-Based `transaction()` API (Rust Core + Python Binding)

## Background

The doc recommends two transaction APIs in the Rust core, with the closure-based
form being primary:

> **Closure-based `transaction()` as primary API** (SeaORM model)
> ```rust
> pool.transaction(|txn| async move {
>     model_a.save(txn).await?;
>     model_b.save(txn).await?;
>     Ok(())
> }).await?;
> ```
> Auto-commit on `Ok`, auto-rollback on `Err`.
>
> **Explicit `begin()`/`commit()`/`rollback()` as secondary API** for cases
> where closures fight with lifetimes.

Currently only the explicit `begin()` API exists. This task adds the closure
form both to `ormpi-core` and exposes a Python-friendly equivalent.

## Design

### Rust

```rust
impl OrmpiPool {
    /// Run `f` inside a transaction.  Commits on `Ok`, rolls back on `Err`.
    ///
    /// This is the **preferred** API for most use-cases.  Use `begin()` only
    /// when you need explicit control over the commit/rollback lifecycle.
    pub async fn transaction<F, Fut, T, E>(
        &self,
        f: F,
    ) -> Result<T, E>
    where
        F: FnOnce(&mut OrmpiTransaction) -> Fut,
        Fut: Future<Output = Result<T, E>>,
        E: From<OrmpiError>,
    {
        let mut txn = OrmpiTransaction::begin(self, "default").await
            .map_err(E::from)?;
        match f(&mut txn).await {
            Ok(val) => {
                txn.commit().await.map_err(E::from)?;
                Ok(val)
            }
            Err(e) => {
                let _ = txn.rollback().await; // best effort
                Err(e)
            }
        }
    }
}
```

### Python binding

Expose `transaction(f, using="default")` as a top-level async function that
accepts an async callable. The callable receives a `Transaction` object:

```python
async def transaction(
    f: Callable[[Transaction], Awaitable[T]],
    *,
    using: str = "default",
) -> T:
    txn = await begin(using=using)
    try:
        result = await f(txn)
        await txn.commit()
        return result
    except BaseException:
        await txn.rollback()
        raise
```

Export from `ormpi.transaction` and re-export from `ormpi` top-level.

## Test Cases

### Unit tests — `ormpi-core/src/transaction.rs`

**TC-4.1 — Closure commits on success**
```rust
#[tokio::test]
async fn transaction_closure_commits_on_ok() {
    let pool = make_test_pool().await;
    pool_exec(&pool, "CREATE TABLE IF NOT EXISTS txn_close(v INT)").await;

    pool.transaction(|txn| async move {
        txn.execute_raw("INSERT INTO txn_close VALUES (7)").await?;
        Ok::<_, OrmpiError>(())
    }).await.unwrap();

    let count: i64 = pool_scalar(&pool, "SELECT COUNT(*) FROM txn_close").await;
    assert_eq!(count, 1);
}
```

**TC-4.2 — Closure rolls back on `Err`**
```rust
#[tokio::test]
async fn transaction_closure_rolls_back_on_err() {
    let pool = make_test_pool().await;
    pool_exec(&pool, "CREATE TABLE IF NOT EXISTS txn_rb(v INT)").await;

    let result = pool.transaction(|txn| async move {
        txn.execute_raw("INSERT INTO txn_rb VALUES (99)").await?;
        Err::<(), OrmpiError>(OrmpiError::Other("forced".into()))
    }).await;

    assert!(result.is_err());
    let count: i64 = pool_scalar(&pool, "SELECT COUNT(*) FROM txn_rb").await;
    assert_eq!(count, 0);
}
```

```rust
async fn transaction_closure_propagates_return_value() {
```

### Integration tests — `__tests__/transactions/test_transaction_fn.py`

**TC-4.6 — Python `transaction()` helper commits on success**
```python
@pytest.mark.asyncio
async def test_transaction_fn_commits():
    from ormpi.transaction import transaction

    async def work(txn):
        await txn.execute_raw(
            "INSERT INTO authors(name, email, active) VALUES ('TxnFn', 'tf@test.com', 1)"
        )

    await transaction(work)
    assert await Author.objects.filter(email="tf@test.com").count() == 1
```

**TC-4.7 — Python `transaction()` helper rolls back on exception**
```python
@pytest.mark.asyncio
async def test_transaction_fn_rolls_back():
    from ormpi.transaction import transaction

    async def bad_work(txn):
        await txn.execute_raw(
            "INSERT INTO authors(name, email, active) VALUES ('WillRB', 'wrb@test.com', 1)"
        )
        raise RuntimeError("abort")

    with pytest.raises(RuntimeError):
        await transaction(bad_work)

    assert await Author.objects.filter(email="wrb@test.com").count() == 0
```

**TC-4.8 — `transaction()` return value propagated to caller**
```python
@pytest.mark.asyncio
async def test_transaction_fn_return_value():

        return author.pk
```
