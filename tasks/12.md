# Task 12: Unify `get_read_alias` / `get_write_alias` in `routing.rs`

## Problem

`ormpi-py/src/routing.rs` contains two functions that are structurally identical. The only difference is the Python method name called on each router (`"db_for_read"` vs `"db_for_write"`):

```rust
// routing.rs lines 42–60
pub fn get_read_alias(model_name: &str, explicit_using: Option<&str>) -> String {
    if let Some(alias) = explicit_using {
        return alias.to_string();
    }
    let chain = ROUTER_CHAIN.lock().unwrap();
    if chain.is_empty() {
        return "default".to_string();
    }
    Python::with_gil(|py| {
        for router in chain.iter() {
            if let Ok(result) = router.bind(py).call_method1("db_for_read", (model_name,)) {
                if let Ok(Some(alias)) = result.extract::<Option<String>>() {
                    return alias;
                }
            }
        }
        "default".to_string()
    })
}

// routing.rs lines 63–81 — byte-for-byte identical except "db_for_write"

```

## Fix

Extract a private `resolve_alias` helper parameterised on the router method name, then rewrite both public functions as one-liners.

### New `ormpi-py/src/routing.rs`

```rust
use std::sync::Mutex;
use pyo3::prelude::*;

static ROUTER_CHAIN: Mutex<Vec<Py<PyAny>>> = Mutex::new(vec![]);

pub fn set_routers(routers: Vec<Py<PyAny>>) {
    *ROUTER_CHAIN.lock().unwrap() = routers;
}

pub fn load_routers(py: Python<'_>, paths: &[String]) -> PyResult<Vec<Py<PyAny>>> {
    // unchanged
}

/// Walk the router chain calling `router_method` on each router until one returns
/// a non-None alias.  If `explicit_using` is set it always wins immediately.
/// Falls back to `"default"` when no router responds.
fn resolve_alias(model_name: &str, explicit_using: Option<&str>, router_method: &str) -> String {
    if let Some(alias) = explicit_using {
        return alias.to_string();
    }
    let chain = ROUTER_CHAIN.lock().unwrap();
    if chain.is_empty() {
        return "default".to_string();
    }
    let method = router_method.to_string(); // capture for with_gil
    Python::with_gil(|py| {
        for router in chain.iter() {
            if let Ok(result) = router.bind(py).call_method1(&method, (model_name,)) {
                if let Ok(Some(alias)) = result.extract::<Option<String>>() {
                    return alias;
                }
            }
        }
        "default".to_string()
    })
}

pub fn get_read_alias(model_name: &str, explicit_using: Option<&str>) -> String {
    resolve_alias(model_name, explicit_using, "db_for_read")
}

pub fn get_write_alias(model_name: &str, explicit_using: Option<&str>) -> String {
    resolve_alias(model_name, explicit_using, "db_for_write")
}
```
