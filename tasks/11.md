# Task 11: Macro-Based `PyManager` Delegation Methods

## Problem

`ormpi-py/src/model/base.rs` `PyManager` (lines 30–302) contains **30+ methods** that all follow the exact same pattern: create a QuerySet, call the same-named method on it, return the result.

Methods with `*args/**kwargs` (like `filter`, `exclude`, `get`, `create`) follow a slightly different pattern but are still boilerplate delegates.

## Fix

Introduce three macros inside `base.rs` to cover the three delegation patterns, then reduce `PyManager` to a `get_queryset` method + macro invocations.

### Macros to add (before `impl PyManager`)

```rust
/// Delegate a zero-argument method to QuerySet.
/// Usage: `delegate_qs0!(method_name)`
macro_rules! delegate_qs0 {
    ($method:ident) => {
        fn $method(&self, py: Python<'_>) -> PyResult<PyObject> {
            let qs = self.get_queryset(py)?;
            qs.bind(py).call_method0(stringify!($method)).map(|r| r.into())
        }
    };
}

/// Delegate a single-argument method to QuerySet.
/// Usage: `delegate_qs1!(method_name, arg_name: ArgType)`
macro_rules! delegate_qs1 {
    ($method:ident, $arg:ident : $arg_ty:ty) => {
        fn $method(&self, py: Python<'_>, $arg: $arg_ty) -> PyResult<PyObject> {
            let qs = self.get_queryset(py)?;
            qs.bind(py).call_method1(stringify!($method), ($arg,)).map(|r| r.into())
        }
    };
}

/// Delegate a *args method (receives a Vec<String>) to QuerySet.
/// Usage: `delegate_qs_args!(method_name)`
macro_rules! delegate_qs_varargs {
    ($method:ident) => {
        #[pyo3(signature = (*fields))]
        fn $method(&self, py: Python<'_>, fields: Vec<String>) -> PyResult<PyObject> {
            let qs = self.get_queryset(py)?;
            let py_args = pyo3::types::PyTuple::new_bound(py, fields.iter().map(|s| s.as_str()));
            qs.bind(py).call_method1(stringify!($method), &py_args).map(|r| r.into())
        }
    };
}
```

### Updated `#[pymethods] impl PyManager`

Replace all repeated method bodies with macro calls:

```rust
#[pymethods]
impl PyManager {
    fn __repr__(&self) -> String { /* keep as-is */ }

    #[getter] fn model_name(&self) -> &str { &self.model_name }
    #[getter] fn app_label(&self) -> &str  { &self.app_label }

    fn get_queryset(&self, py: Python<'_>) -> PyResult<PyObject> { /* keep as-is */ }

    fn all(&self, py: Python<'_>) -> PyResult<PyObject> {
        let qs = self.get_queryset(py)?;
        qs.bind(py).call_method0("all").map(|r| r.into())
    }

    // Zero-argument delegates
    delegate_qs0!(none);
    delegate_qs0!(count);
    delegate_qs0!(exists);
    delegate_qs0!(first);
    delegate_qs0!(last);
    delegate_qs0!(distinct);
    delegate_qs0!(reverse);

    // Single-argument delegates
    delegate_qs1!(using,   alias: String);
    delegate_qs1!(earliest, field: String);
    delegate_qs1!(latest,   field: String);

    // *fields varargs delegates
    delegate_qs_varargs!(order_by);
    delegate_qs_varargs!(only);
    delegate_qs_varargs!(defer);
    delegate_qs_varargs!(values);

    // *args/**kwargs delegates — keep manual (kwargs pattern differs)
    #[pyo3(signature = (*args, **kwargs))]
    fn filter(&self, py: Python<'_>, args: &Bound<'_, PyTuple>, kwargs: Option<&Bound<'_, PyDict>>) -> PyResult<PyObject> {
        let qs = self.get_queryset(py)?;
        qs.bind(py).call_method("filter", args, kwargs).map(|r| r.into())
    }
    // ... exclude, get, create, annotate, aggregate, select_related,
    //     prefetch_related, bulk_create, bulk_update, get_or_create,
    //     update_or_create, values_list, raw — same manual pattern, keep as-is
    //     since they need kwargs or custom signatures
}
```

> **Note on `values_list`**: currently delegates as a *args method but has an extra `flat` keyword. Keep it manual or extend `delegate_qs_varargs!` to support an optional extra kwarg.
