# Task 7 — `.transaction(txn)` on QuerySet/Manager + `transaction=` on Instance Methods

## Background

The doc's reference architecture routes all ORM operations through a
`Connectable` abstraction. This task exposes that at the Python API layer.

Two complementary surfaces are added:

**QuerySet/Manager** — a `.transaction(txn)` chaining method, mirroring Django's
`.using("db_alias")` for database routing. It binds a `Transaction` to the
QuerySet clone and all downstream clones inherit it automatically. No existing
method signature changes.

**Instance methods** (`save`, `delete`) — a `transaction=` keyword parameter,
since there is no chain target on a model instance.

```python
# QuerySet — chaining (primary style)
qs = Author.objects.transaction(txn)
await qs.create(name="Alice", email="a@test.com")
await qs.filter(active=True).delete()       # filter() inherits txn via _clone()
await qs.filter(name="Alice").update(age=30)

# Instance methods — keyword (only place it's needed)
await author.save(transaction=txn)
await author.delete(transaction=txn)
```

Ambient ContextVar transaction (Task 5) remains the zero-signature fallback:
when neither `.transaction(txn)` nor `transaction=` is provided, execution
checks the ContextVar before falling back to the pool.

## Design

### QuerySet `_transaction` field + `_clone()` propagation

```rust
// ormpi-py/src/query/queryset.rs  (simplified)
#[pyclass]
pub struct QuerySet {
    model_name: String,
    filters: Vec<Filter>,
    // ... other existing fields ...
    transaction: Option<Arc<tokio::sync::Mutex<Option<OrmpiTransaction>>>>,
}

impl QuerySet {
    fn _clone(&self) -> Self {
        QuerySet {
            transaction: self.transaction.clone(), // Arc clone — free
            // ... copy other fields ...
        }
    }
}

#[pymethods]
impl QuerySet {
    /// Bind a transaction to this QuerySet.
    /// Returns a new QuerySet clone; the original is unchanged.
    fn transaction(&self, txn: &PyTransaction) -> Self {
        let mut qs = self._clone();
        qs.transaction = Some(txn.inner_arc());
        qs
    }
}
```

### Connection resolution order in every execution path

```rust
fn resolve_connectable<'a>(
    qs_txn: &'a Option<Arc<…>>,
    pool: &'a OrmpiPool,
) -> ConnRef<'a> {
    // 1. Explicit: QuerySet-bound transaction
    if let Some(arc) = qs_txn {
        return ConnRef::Transaction(arc.clone());
    }
    // 2. Ambient: ContextVar transaction (checked via Python GIL call)
    if let Some(ambient) = get_ambient_transaction() {
        return ConnRef::Transaction(ambient);
    }
    // 3. Pool fallback
    ConnRef::Pool(pool)
}
```

### Instance method `transaction=` keyword

```rust
#[pymethods]
impl PyModel {
    #[pyo3(signature = (update_fields = None, transaction = None))]
    fn save<'py>(
        &mut self,
        py: Python<'py>,
        update_fields: Option<Vec<String>>,
        transaction: Option<&PyTransaction>,
    ) -> PyResult<PyObject> { … }

    #[pyo3(signature = (transaction = None))]
    fn delete<'py>(
        &mut self,
        py: Python<'py>,
        transaction: Option<&PyTransaction>,
    ) -> PyResult<PyObject> { … }
}
```


## Test Cases

### `__tests__/transactions/test_qs_transaction.py`

**TC-7.1 — `.transaction(txn).create()` is invisible to pool before commit**
```python
@pytest.mark.asyncio
async def test_create_invisible_before_commit():
    txn = await ormpi.begin()
    await Author.objects.transaction(txn).create(name="InTxn", email="intxn@test.com")

    assert await Author.objects.filter(email="intxn@test.com").count() == 0

    await txn.rollback()
    assert await Author.objects.filter(email="intxn@test.com").count() == 0
```

**TC-7.2 — `.transaction(txn).create()` is visible after commit**
```python
@pytest.mark.asyncio
async def test_create_visible_after_commit():
    txn = await ormpi.begin()
    await Author.objects.transaction(txn).create(name="Committed", email="c@test.com")
    await txn.commit()

    assert await Author.objects.filter(email="c@test.com").count() == 1
```

**TC-7.3 — `.transaction(txn)` is inherited by `.filter()` chained after it**
```python
@pytest.mark.asyncio
async def test_transaction_inherited_by_filter():
    author = await Author.objects.create(name="Orig", email="orig@test.com")
    txn = await ormpi.begin()

    await Author.objects.transaction(txn).filter(pk=author.pk).update(name="Changed")

    # Pool still sees old value
    assert (await Author.objects.get(pk=author.pk)).name == "Orig"
    await txn.rollback()
    assert (await Author.objects.get(pk=author.pk)).name == "Orig"
```

**TC-7.4 — Original QuerySet is unmodified after `.transaction()` call**
```python
@pytest.mark.asyncio
async def test_transaction_returns_new_qs_clone():
    txn = await ormpi.begin()
    base_qs = Author.objects.all()
    txn_qs  = base_qs.transaction(txn)

    assert txn_qs is not base_qs
    # base_qs has no transaction bound — still uses pool
    await Author.objects.create(name="Visible", email="v@test.com")
    assert await base_qs.count() == 1   # pool query works fine

    await txn.rollback()
```

**TC-7.5 — `.transaction(txn).delete()` is rolled back**
```python
@pytest.mark.asyncio
async def test_delete_via_transaction_rollback():
    author = await Author.objects.create(name="Del", email="del@test.com")
    txn = await ormpi.begin()

    await Author.objects.transaction(txn).filter(pk=author.pk).delete()
    assert await Author.objects.filter(pk=author.pk).count() == 1  # not committed

    await txn.rollback()
    assert await Author.objects.filter(pk=author.pk).count() == 1
```

**TC-7.6 — `.transaction(txn).bulk_create()` is rolled back**
```python
@pytest.mark.asyncio
async def test_bulk_create_via_transaction_rollback():
    objs = [Author(name=f"B{i}", email=f"b{i}@test.com") for i in range(3)]
    txn  = await ormpi.begin()

    await Author.objects.transaction(txn).bulk_create(objs)
    assert await Author.objects.count() == 0  # not visible yet

    await txn.rollback()
    assert await Author.objects.count() == 0
```

**TC-7.7 — `.transaction(txn).get_or_create()` creates inside transaction**
```python
@pytest.mark.asyncio
async def test_get_or_create_inside_transaction():
    txn = await ormpi.begin()
    obj, created = await Author.objects.transaction(txn).get_or_create(
        email="goc@test.com", defaults={"name": "Goc"}
    )
    assert created is True
    assert await Author.objects.filter(email="goc@test.com").count() == 0

    await txn.commit()
    assert await Author.objects.filter(email="goc@test.com").count() == 1
```

### Ambient + precedence tests

**TC-7.10 — Ambient transaction is used when no `.transaction()` and no keyword**
```python
@pytest.mark.asyncio
async def test_ambient_transaction_auto_used():
    async with ormpi.transaction.atomic():
        await Author.objects.create(name="Ambient", email="amb@test.com")
        assert await Author.objects.filter(email="amb@test.com").count() == 0

    assert await Author.objects.filter(email="amb@test.com").count() == 1
```

**TC-7.11 — Explicit `.transaction(txn)` takes precedence over ambient**
```python
@pytest.mark.asyncio
async def test_explicit_transaction_overrides_ambient():
    explicit_txn = await ormpi.begin()

    async with ormpi.transaction.atomic():
        # Write via explicit txn — independent of the ambient one
        await Author.objects.transaction(explicit_txn).create(
            name="Explicit", email="exp@test.com"
        )

    # Ambient committed; explicit not yet
    assert await Author.objects.filter(email="exp@test.com").count() == 0

    await explicit_txn.commit()
    assert await Author.objects.filter(email="exp@test.com").count() == 1
```

**TC-7.12 — No transaction anywhere uses pool (backwards compatible)**
```python
@pytest.mark.asyncio
async def test_no_transaction_uses_pool():
    await Author.objects.create(name="Plain", email="plain@test.com")
    assert await Author.objects.filter(email="plain@test.com").count() == 1
```

## Acceptance Criteria

- [ ] `QuerySet.transaction(txn)` and `Manager.transaction(txn)` added —
  returns a new QuerySet clone with `_transaction` bound.
- [ ] `_transaction` is propagated through every `_clone()` call so `.filter()`,
  `.exclude()`, `.order_by()` etc. all inherit it automatically.
- [ ] All QuerySet execution paths (`create`, `update`, `delete`,
  `get_or_create`, `update_or_create`, `bulk_create`, `bulk_update`) respect
  `_transaction` when set.
- [ ] `Model.save(transaction=None)` and `Model.delete(transaction=None)`
  accept an optional `Transaction` keyword argument.
- [ ] Connection resolution order: explicit QS-bound > ambient ContextVar >
  pool.
- [ ] Original QuerySet is never mutated by `.transaction()` (clone semantics).
- [ ] TC-7.1 through TC-7.12 all pass under `pytest`.
- [ ] Type stubs updated: `QuerySet.transaction()` and `Manager.transaction()`
  typed as returning `QuerySet[_M]`.
- [ ] Mypy / pyright pass on modified files.
- [ ] All existing `__tests__/crud/` tests pass with no changes — no `using=`
  or `transaction=` kwargs were present before, so full backwards compatibility
  is required.
