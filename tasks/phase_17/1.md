## Bug 1 — `values()` Does Not Accept Field Arguments

### Current state

`QuerySet.values()` in `queryset.rs` takes no arguments:
```rust
fn values(slf: Bound<'_, Self>) -> PyResult<PyObject> {
    state.result_type = ResultType::Values;
    ...
}
```

`Manager.values()` in `base.rs` also takes no arguments.

### Expected usage in tests

```python
await Author.objects.values("name", "age")       # returns list of dicts
await Author.objects.values("name").distinct()    # distinct on projected field
```

### Fix — `queryset.rs`: accept optional field names

```rust
#[pyo3(signature = (*fields))]
fn values(slf: Bound<'_, Self>, fields: Vec<String>) -> PyResult<PyObject> {
    let mut state = slf.borrow().state.clone();
    let model_class = clone_model_class(py, &slf.borrow().model_class);
    state.result_type = ResultType::Values;
    if !fields.is_empty() {
        state.select_fields = SelectFields::Only(fields);
    }
    Ok(Py::new(py, PyQuerySet { state, model_class, transaction_arc: ... })?.into_py(py))
}
```

### Fix — `base.rs` Manager: proxy with fields

```rust
#[pyo3(signature = (*fields))]
fn values(&self, py: Python<'_>, fields: Vec<String>) -> PyResult<PyObject> {
    let qs = self.get_queryset(py)?;
    let py_fields = pyo3::types::PyTuple::new_bound(py, fields.iter().map(|s| s.as_str()));
    qs.bind(py).call_method1("values", &py_fields).map(|r| r.into())
}
```

## Bug 2 — `values_list()` Missing Entirely

### Expected usage

```python
await Author.objects.values_list("name", "age")           # list of tuples
await Author.objects.values_list("name", flat=True)       # flat list of values
```

### Fix — Add `ResultType::ValuesList` and `ResultType::ValuesListFlat`

**File:** `ormpi-core/src/query/state.rs` (or wherever `ResultType` is defined):

```rust
pub enum ResultType {
    Instances,
    Values,
    ValuesList,         // ← NEW: list of tuples
    ValuesListFlat,     // ← NEW: list of single values (flat=True)
}
```

**File:** `ormpi-py/src/query/queryset.rs`: Add `values_list` method

```rust
#[pyo3(signature = (*fields, flat = false))]
fn values_list(
    slf: Bound<'_, Self>,
    fields: Vec<String>,
    flat: bool,
) -> PyResult<PyObject> {
    let py = slf.py();
    let mut state = slf.borrow().state.clone();
    let model_class = clone_model_class(py, &slf.borrow().model_class);
    state.result_type = if flat {
        ResultType::ValuesListFlat
    } else {
        ResultType::ValuesList
    };
    if !fields.is_empty() {
        state.select_fields = SelectFields::Only(fields);
    }
    Ok(Py::new(py, PyQuerySet { state, model_class, transaction_arc: slf.borrow().transaction_arc.clone() })?.into_py(py))
}
```

**File:** `ormpi-py/src/model/base.rs` Manager: proxy `values_list`

```rust
#[pyo3(signature = (*fields, flat = false))]
fn values_list(
    &self,
    py: Python<'_>,
    fields: Vec<String>,
    flat: bool,
) -> PyResult<PyObject> {
    let qs = self.get_queryset(py)?;
    let kwargs = PyDict::new_bound(py);
    kwargs.set_item("flat", flat)?;
    let py_fields = pyo3::types::PyTuple::new_bound(py, fields.iter().map(|s| s.as_str()));
    qs.bind(py)
        .call_method("values_list", py_fields, Some(&kwargs))
        .map(|r| r.into())
}
```

**File:** `ormpi-core/src/query/evaluate.rs`: Add result-type handling for `ValuesList` / `ValuesListFlat`

When building the result set after fetching rows:
- `ResultType::ValuesList`: return `list[tuple[Any, ...]]` — collect each selected field into a Python tuple per row.
- `ResultType::ValuesListFlat`: return `list[Any]` — exactly one field selected; flatten to a bare list.

```rust
ResultType::ValuesList => {
    let tuples: Vec<PyObject> = rows.iter().map(|row| {
        let vals: Vec<PyObject> = selected_fields.iter()
            .map(|f| ormpi_value_to_py(py, row.get(f).unwrap_or(&OrmpiValue::Null)))
            .collect();
        pyo3::types::PyTuple::new_bound(py, vals).into()
    }).collect();
    Ok(pyo3::types::PyList::new_bound(py, tuples).into())
}
ResultType::ValuesListFlat => {
    let field = selected_fields.first()
        .ok_or_else(|| pyo3::exceptions::PyValueError::new_err(
            "values_list(flat=True) requires exactly one field"
        ))?;
    let items: Vec<PyObject> = rows.iter()
        .map(|row| ormpi_value_to_py(py, row.get(field).unwrap_or(&OrmpiValue::Null)))
        .collect();
    Ok(pyo3::types::PyList::new_bound(py, items).into())
}
```
