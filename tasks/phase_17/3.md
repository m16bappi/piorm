## Bug 1 — `reverse()` Missing from QuerySet

### Expected usage

```python
desc = await Author.objects.order_by("age").reverse()
# equivalent to order_by("-age")
```

`reverse()` flips the sign of every ordering in the current `order_by` list.
If no ordering is set, adds `ORDER BY id DESC`.

### Fix — `queryset.rs`

```rust
/// Reverse the current ordering (or default to pk DESC if no ordering is set).
fn reverse(slf: Bound<'_, Self>) -> PyResult<PyObject> {
    let py = slf.py();
    let mut state = slf.borrow().state.clone();
    let model_class = clone_model_class(py, &slf.borrow().model_class);
    if state.order_by.is_empty() {
        state.order_by = vec![OrderSpec {
            field: "id".to_string(),
            descending: true,
            nulls_last: false,
            nulls_first: false,
        }];
    } else {
        for o in &mut state.order_by {
            o.descending = !o.descending;
        }
    }
    Ok(Py::new(py, PyQuerySet { state, model_class, transaction_arc: slf.borrow().transaction_arc.clone() })?.into_py(py))
}
```

## Bug 2 — `iterator(chunk_size)` Missing from QuerySet

### Expected usage

```python
async for author in Author.objects.all().iterator(chunk_size=2):
    process(author)
```

`iterator()` returns an async generator that fetches rows in `chunk_size` batches and
yields model instances one at a time.

### Fix — `queryset.rs`

`iterator()` should return a `PyAsyncIter` (the same type already used by `__aiter__`).

```rust
#[pyo3(signature = (chunk_size = 2000))]
fn iterator(slf: Bound<'_, Self>, chunk_size: usize) -> PyResult<PyObject> {
    let py = slf.py();
    let mut state = slf.borrow().state.clone();
    let model_class = clone_model_class(py, &slf.borrow().model_class);
    // Use chunk_size as the batch limit for the async iterator
    // The simplest implementation: fetch all rows and wrap in PyAsyncIter
    // A full streaming implementation is a future optimisation.
    let iter = crate::query::iter::PyAsyncIter::new_from_state(state, model_class, chunk_size);
    Ok(Py::new(py, iter)?.into_py(py))
}
```

Look at the existing `PyAsyncIter` implementation in `query/iter.rs` and wire
`iterator()` to create one with the same state. The `chunk_size` parameter can be used
to set a fetch limit per batch; for a first implementation it is acceptable to ignore it
and fetch all rows (same as `__aiter__`).

**The key requirement:** `iterator()` must return something that supports `async for`.

## Bug 3 — `__getitem__` Single Int Index Returns Non-Awaitable

### Expected usage

```python
author = await Author.objects.all()[0]   # get first row
```

### Current state

`QuerySet.__getitem__` already handles `int` keys:

```rust
fn __getitem__(slf: Bound<'_, Self>, key: &Bound<'_, PyAny>) -> PyResult<PyObject> {
    if let Ok(idx) = key.extract::<i64>() {
        let mut state = ...;
        if idx >= 0 {
            state.offset = Some(idx as u64);
```

But the method currently returns a `PyObject` synchronously (a new `PyQuerySet`), not a
coroutine. The test does `await qs[0]` which means it expects a coroutine that resolves
to an instance.

### Fix — `queryset.rs`, `__getitem__` int branch

For int indices, fetch the single row and return it as a coroutine (like `first()`):

```rust
if let Ok(idx) = key.extract::<i64>() {
    let mut state = slf.borrow().state.clone();
    let model_class = clone_model_class(py, &slf.borrow().model_class);
    if idx >= 0 {
        state.offset = Some(idx as u64);
        state.limit  = Some(1);
    } else {
        // Negative index: e.g. [-1] means last row
        // Reverse ordering and use positive offset
        let abs_idx = (-idx - 1) as u64;
        for o in &mut state.order_by {
            o.descending = !o.descending;
        }
        state.offset = Some(abs_idx);
        state.limit  = Some(1);
    }

    return pyo3_async_runtimes::tokio::future_into_py(py, async move {
        let rows = fetch_rows_for_state(&state).await
            .map_err(|e| Python::with_gil(|_py| crate::ormpi_err(e)))?;
        Python::with_gil(|py| {
            if rows.is_empty() {
                return Err(pyo3::exceptions::PyIndexError::new_err("index out of range"));
            }
            match &model_class {
                Some(cls) => row_to_instance(py, &rows[0], cls),
                None => Ok(py.None()),
            }
        })
    })
    .map(|b| b.into());
}
```
