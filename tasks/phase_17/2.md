# Task 17.2 — Add Missing Manager Proxies: `only`, `defer`, `raw`, `earliest`, `latest`

## Failing Tests

```
TestDeferredLoading::test_only_loads_specified_fields
TestDeferredLoading::test_defer_excludes_specified_fields
TestRawSQL::test_raw_returns_model_instances
TestRawSQL::test_raw_with_params
TestEdgeRetrievals::test_earliest_by_field
TestEdgeRetrievals::test_latest_by_field
```

Errors:
```python
AttributeError: 'builtins.Manager' object has no attribute 'only'
AttributeError: 'builtins.Manager' object has no attribute 'raw'
AttributeError: 'builtins.Manager' object has no attribute 'earliest'
AttributeError: 'builtins.Manager' object has no attribute 'latest'. Did you mean: 'last'?
AttributeError: 'builtins.QuerySet' object has no attribute 'raw_with_params'
```

## Root Cause

`QuerySet` in `queryset.rs` has `only()` and `defer()` methods, but `Manager` in `base.rs`
does NOT proxy them. `raw()`, `earliest()`, and `latest()` are missing from both.

---

## Fix 1 — Add `only` / `defer` proxies to Manager (`base.rs`)

The QuerySet methods already exist. Just proxy from Manager:

```rust
#[pyo3(signature = (*fields))]
fn only(&self, py: Python<'_>, fields: Vec<String>) -> PyResult<PyObject> {
    let qs = self.get_queryset(py)?;
    let py_fields = pyo3::types::PyTuple::new_bound(py, fields.iter().map(|s| s.as_str()));
    qs.bind(py).call_method1("only", py_fields).map(|r| r.into())
}

#[pyo3(signature = (*fields))]
fn defer(&self, py: Python<'_>, fields: Vec<String>) -> PyResult<PyObject> {
    let qs = self.get_queryset(py)?;
    let py_fields = pyo3::types::PyTuple::new_bound(py, fields.iter().map(|s| s.as_str()));
    qs.bind(py).call_method1("defer", py_fields).map(|r| r.into())
}
```

Also update `QuerySet.only()` / `defer()` signatures to accept `*fields` (variadic) if they
currently take a `Vec<String>` without the `*args` signature decorator:

```rust
// queryset.rs
#[pyo3(signature = (*fields))]
fn only(slf: Bound<'_, Self>, fields: Vec<String>) -> PyResult<PyObject> { ... }

#[pyo3(signature = (*fields))]
fn defer(slf: Bound<'_, Self>, fields: Vec<String>) -> PyResult<PyObject> { ... }
```

## Fix 2 — Add `earliest(field)` / `latest(field)` to Manager and QuerySet

These are sugar for `order_by(field).first()` and `order_by("-field").first()`.

**In `queryset.rs`:**

```rust
/// Return the earliest row ordered by `field` (ASC).
fn earliest(slf: Bound<'_, Self>, field: String) -> PyResult<PyObject> {
    let py = slf.py();
    let qs = slf.call_method1("order_by", (field,))?;
    qs.call_method0("first").map(|r| r.into())
}

/// Return the latest row ordered by `field` (DESC).
fn latest(slf: Bound<'_, Self>, field: String) -> PyResult<PyObject> {
    let py = slf.py();
    let desc_field = format!("-{}", field);
    let qs = slf.call_method1("order_by", (desc_field,))?;
    qs.call_method0("first").map(|r| r.into())
}
```

**In `base.rs` Manager:**

```rust
fn earliest(&self, py: Python<'_>, field: String) -> PyResult<PyObject> {
    let qs = self.get_queryset(py)?;
    qs.bind(py).call_method1("earliest", (field,)).map(|r| r.into())
}

fn latest(&self, py: Python<'_>, field: String) -> PyResult<PyObject> {
    let qs = self.get_queryset(py)?;
    qs.bind(py).call_method1("latest", (field,)).map(|r| r.into())
}
```

## Fix 3 — Add `raw(sql, params)` to Manager and QuerySet

### Usage in tests

```python
async for row in Author.objects.raw("SELECT * FROM authors"):
    assert row.pk is not None

rows = await Author.objects.raw("SELECT * FROM authors WHERE age > %s", [25])
```

`raw()` executes a SQL string and returns an async-iterable (or awaitable list) of model
instances hydrated from the raw result columns.

**In `queryset.rs`:**

```rust
#[pyo3(signature = (sql, params = None))]
fn raw(
    slf: Bound<'_, Self>,
    sql: String,
    params: Option<Vec<PyObject>>,
) -> PyResult<PyObject> {
    let py = slf.py();
    let state = slf.borrow().state.clone();
    let model_class = clone_model_class(py, &slf.borrow().model_class);

    pyo3_async_runtimes::tokio::future_into_py(py, async move {
        use ormpi_core::registry::DatabaseRegistry;
        let db_alias = state.database.clone().unwrap_or_else(|| "default".to_string());
        let pool = { ... get pool ... };

        let ormpi_params: Vec<OrmpiValue> = ...;  // convert params
        let rows = ormpi_core::executor::execute_raw_select(&sql, &ormpi_params, &pool).await
            .map_err(|e| Python::with_gil(|_py| crate::ormpi_err(e)))?;

        Python::with_gil(|py| {
            let instances: Vec<PyObject> = rows.iter()
                .filter_map(|row| {
                    model_class.as_ref().and_then(|cls| row_to_instance(py, row, cls).ok())
                })
                .collect();
            Ok::<PyObject, PyErr>(pyo3::types::PyList::new_bound(py, instances).into())
        })
    })
    .map(|b| b.into())
}
```

**In `base.rs` Manager:**

```rust
#[pyo3(signature = (sql, params = None))]
fn raw(&self, py: Python<'_>, sql: String, params: Option<PyObject>) -> PyResult<PyObject> {
    let qs = self.get_queryset(py)?;
    let kwargs = None::<&pyo3::types::PyDict>;
    qs.bind(py)
        .call_method("raw", (sql, params), kwargs)
        .map(|r| r.into())
}
```

The `ormpi_core::executor::execute_raw_select` function needs to be added (or reused from
the existing `execute_raw` which returns a single row — extend it to return all rows as a
`Vec<HashMap<String, OrmpiValue>>`).
