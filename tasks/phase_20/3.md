## Root Cause

`atomic` is currently a context-manager-only class. Django supports three equivalent forms:

```python
# Context manager (already works)
async with atomic():
    ...

# Bare decorator (missing)
@atomic
async def my_view():
    ...

# Decorator with arguments (missing)
@atomic()
async def my_view():
    ...

@atomic(using="secondary")
async def my_view():
    ...
```

The bare `@atomic` form is especially important because it's the most common Django pattern
for wrapping entire view/service functions in a transaction.

## Fix — `ormpi-py/src/transaction.rs` + Python `transaction.py`

All decorator logic lives in **Rust** via `PyTransaction`'s module-level infrastructure, but
the wrapping of async coroutines must be done at the Python level since `pyo3-async-runtimes`
does not have a generic "wrap any Python coroutine" primitive.

### Strategy: Add `__call__` to the `atomic` Python class

The `atomic` class in `python/ormpi/transaction.py` gains a `__call__` method. When `atomic`
is used as a decorator, Python calls `atomic.__call__(func)` to produce the wrapper.

Implement the entire decorator machinery in Rust by adding a new `PyAtomic` class (or by
modifying the existing `atomic` Python class):

### Step 1 — Expose `PyAtomicDecorator` from Rust (`ormpi-py/src/transaction.rs`)

Add a Rust helper that wraps an async callable:

```rust
/// Wraps a Python async callable so it runs inside an atomic() block.
#[pyclass(name = "_AtomicWrapper")]
pub struct PyAtomicWrapper {
    func: Py<PyAny>,
    using: String,
}

#[pymethods]
impl PyAtomicWrapper {
    #[pyo3(signature = (*args, **kwargs))]
    fn __call__(
        &self,
        py: Python<'_>,
        args: &Bound<'_, pyo3::types::PyTuple>,
        kwargs: Option<&Bound<'_, pyo3::types::PyDict>>,
    ) -> PyResult<PyObject> {
        let func = self.func.clone_ref(py);
        let using = self.using.clone();
        let args_owned: Py<pyo3::types::PyTuple> = args.into_py(py).extract(py)?;
        let kwargs_owned: Option<Py<pyo3::types::PyDict>> = kwargs
            .map(|kw| kw.into_py(py).extract::<Py<pyo3::types::PyDict>>(py))
            .transpose()?;

        // Build a coroutine that runs func(*args, **kwargs) inside atomic(using=...).
        // We must return an awaitable, so we produce a Python coroutine via
        // pyo3_async_runtimes::tokio::future_into_py.
        pyo3_async_runtimes::tokio::future_into_py(py, async move {
            // Acquire the transaction.
            let txn = Python::with_gil(|py| {
                let begin_fn = py.import_bound("ormpi._core")?.getattr("begin")?;
                let coro = begin_fn.call1((&using,))?;
                Ok::<PyObject, PyErr>(coro.into())
            })?;

            // Await begin().
            // NOTE: because pyo3-async-runtimes' future_into_py runs inside Tokio,
            // we cannot easily await Python coroutines here without going through
            // the Python event loop.  Use the Python-level atomic() context manager
            // instead (see Step 2 for the pure-Python approach).
            todo!()
        })
        .map(|b| b.into())
    }
}
```

Because awaiting a Python coroutine from Rust requires bridging two async runtimes, the
cleanest fully-Rust implementation delegates to an **inner Python coroutine** defined
in `transaction.py`, while the Rust layer only provides the class scaffold for `__call__`.

### Step 2 — Implement in Python `transaction.py` (Rust-registered, still the right layer)

Add `__call__` to the existing `atomic` class. This is **pure Python glue** — no new
Python files, no non-Rust code outside `transaction.py`:

```python
import functools
import inspect

class atomic:
    # ... existing __init__, __aenter__, __aexit__ ...

    def __call__(self, func):
        """Allow @atomic and @atomic() as a decorator for async functions."""
        if not inspect.iscoroutinefunction(func):
            raise TypeError(
                f"@atomic can only decorate async functions, got {func!r}"
            )

        @functools.wraps(func)
        async def wrapper(*args, **kwargs):
            async with atomic(using=self._using):
                return await func(*args, **kwargs)

        return wrapper
```

To support the **bare** `@atomic` form (without parentheses), detect when `atomic` is
called with a single callable argument in `__init__`:

```python
def __init__(self, using: str = "default", _func=None) -> None:
    self._using = using
    self._txn: Transaction | None = None
    self._savepoint_name: str | None = None
    self._is_nested = False
    # Bare decorator: @atomic (no parentheses)
    if callable(using):
        # atomic(func) — user wrote @atomic without ()
        self._wrapped_func = using   # `using` is actually the function
        self._using = "default"
    else:
        self._wrapped_func = _func
```

Then `atomic.__new__` or `__init_subclass__` can return the wrapper directly if
`_wrapped_func` is set. The cleanest pattern: override `__new__`:

```python
def __new__(cls, using="default"):
    if callable(using):
        # Bare @atomic — `using` is actually the decorated function.
        func = using
        instance = super().__new__(cls)
        instance.__init__(using="default")
        return instance(func)   # returns the wrapper, not an atomic instance
    return super().__new__(cls)
```

## New Tests to Add (`__tests__/crud/test_transaction.py`)

```python
class TestAtomicDecorator:

    @pytest.mark.asyncio
    async def test_decorator_commits_on_success(self):
        @atomic()
        async def insert():
            await Author.objects.create(name="Alice", email="alice@test.com")

        await insert()
        assert await Author.objects.count() == 1

    @pytest.mark.asyncio
    async def test_decorator_rollback_on_exception(self):
        @atomic()
        async def fail_insert():
            await Author.objects.create(name="Alice", email="alice@test.com")
            raise ValueError("abort")

        with pytest.raises(ValueError):
            await fail_insert()

        assert await Author.objects.count() == 0

    @pytest.mark.asyncio
    async def test_bare_decorator_commits(self):
        @atomic
        async def insert():
            await Author.objects.create(name="Alice", email="alice@test.com")

        await insert()
        assert await Author.objects.count() == 1

    @pytest.mark.asyncio
    async def test_decorator_preserves_return_value(self):
        @atomic()
        async def insert_and_return():
            return await Author.objects.create(name="Alice", email="alice@test.com")

        author = await insert_and_return()
        assert author.name == "Alice"

    @pytest.mark.asyncio
    async def test_decorator_exception_propagates(self):
        class Boom(Exception):
            pass

        @atomic()
        async def raiser():
            raise Boom("boom")

        with pytest.raises(Boom, match="boom"):
            await raiser()
```
