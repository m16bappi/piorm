# Task 10: Extract `apply_ddl_for_model` to Eliminate 3× Identical DDL Execution Block

## Problem

The following block appears **verbatim three times** in `piorm-py/src/lib.rs`:

```rust
// Appears in: configure() lines 149–172, create_table() lines 331–356, create_all_tables() lines 389–411
piorm_core::executor::execute_sql(&pool, &ddl.create_table)
    .await
    .map_err(piorm_err)?;

for sql in &ddl.create_indexes {
    piorm_core::executor::execute_sql(&pool, sql)
        .await
        .map_err(piorm_err)?;
}

for sql in &ddl.create_m2m_tables {
    piorm_core::executor::execute_sql(&pool, sql)
        .await
        .map_err(piorm_err)?;
}

for sql in &ddl.create_fk_constraints {
    if !sql.starts_with("--") {
        piorm_core::executor::execute_sql(&pool, sql)
            .await
            .map_err(piorm_err)?;
    }
}
```

The `configure()` and `create_all_tables()` functions also share the same "snapshot all model defs, get pool, loop over models, run DDL" structure — only the loop source differs (`all_defs` from registry vs argument).

## Fix

### Step 1 — Extract `apply_ddl_for_model` async helper

Add inside `lib.rs` (before the `#[pymodule]` block):

```rust
/// Execute all DDL statements for a single model against the given pool.
/// Skips FK constraint statements that start with `--` (SQLite comments).
async fn apply_ddl_for_model(
    pool: &piorm_core::pool::PiormPool,
    ddl: &piorm_core::model::ddl::ModelDdl,
) -> PyResult<()> {
    piorm_core::executor::execute_sql(pool, &ddl.create_table)
        .await
        .map_err(piorm_err)?;

    for sql in &ddl.create_indexes {
        piorm_core::executor::execute_sql(pool, sql)
            .await
            .map_err(piorm_err)?;
    }

    for sql in &ddl.create_m2m_tables {
        piorm_core::executor::execute_sql(pool, sql)
            .await
            .map_err(piorm_err)?;
    }

    for sql in &ddl.create_fk_constraints {
        if !sql.starts_with("--") {
            piorm_core::executor::execute_sql(pool, sql)
                .await
                .map_err(piorm_err)?;
        }
    }

    Ok(())
}
```

### Step 2 — Update `configure()` (lines 149–172)

Replace the manual DDL loop body with:

```rust
// Before (inside: for model_def in &all_defs { ... }):
let ddl = piorm_core::model::ddl::model_to_ddl(model_def, backend);

piorm_core::executor::execute_sql(&pool, &ddl.create_table).await.map_err(piorm_err)?;
for sql in &ddl.create_indexes { ... }
for sql in &ddl.create_m2m_tables { ... }
for sql in &ddl.create_fk_constraints { if !sql.starts_with("--") { ... } }

// After:
let ddl = piorm_core::model::ddl::model_to_ddl(model_def, backend);
apply_ddl_for_model(&pool, &ddl).await?;
```
