# Task 5 — Replace Task-ID Dict with `contextvars.ContextVar` for Ambient Propagation

## Background

`python/ormpi/_transaction_local.py` currently stores the active transaction in
a plain `dict` keyed on `id(asyncio.current_task())`:

```python
_CURRENT: dict[int, dict[str, Any]] = {}

def _get_current_transaction(using: str) -> Any:
    task = asyncio.current_task()
    if task is None:
        return None
    return _CURRENT.get(id(task), {}).get(using)
```

This approach has two serious problems the doc warns about:

1. **Memory leak / ID reuse.** `id(task)` is the memory address of the task
   object. Once the task is garbage-collected, a new task may reuse the same
   address. The stale entry is never cleaned up because there is no GC hook.

2. **Not ContextVar semantics.** `asyncio.create_task()` copies the parent's
   `contextvars` context. When tasks are nested, the dict mutation is shared
   (global state), so a child task **can accidentally inherit the parent's
   transaction** unless the dict is explicitly wiped — the exact footgun the
   doc warns about.

The doc's recommended pattern (Piccolo / Tortoise) is:

```python
_current_conn: ContextVar[Optional[Transaction]] = ContextVar(
    'ormpi_current_transaction', default=None
)
```

`ContextVar` gives each `asyncio.create_task()` a **copy** of the parent's
context. Mutations in the child do not affect the parent. Each `atomic()`
context manager sets and then resets (via `.reset(token)`) the variable,
enabling correct nesting.

## Design

```python
# python/ormpi/_transaction_local.py

from contextvars import ContextVar, Token
from typing import Any

# One ContextVar per database alias is possible but complex.
# Instead, store a dict[alias, Transaction] in a single ContextVar.
# An empty dict means "no active transaction".
_current: ContextVar[dict[str, Any]] = ContextVar(
    'ormpi_current_transaction', default={}
)


def _get_current_transaction(using: str) -> Any:
    return _current.get().get(using)


def _set_current_transaction(using: str, txn: Any) -> Token:
    """Set the active transaction and return the reset token."""
    new_ctx = {**_current.get(), using: txn}
    return _current.set(new_ctx)


def _reset_current_transaction(token: Token) -> None:
    """Restore prior context state via the token from _set_current_transaction."""
    _current.reset(token)
```

`atomic.__aenter__` stores the token returned by `_set_current_transaction`;
`atomic.__aexit__` calls `_reset_current_transaction(token)` rather than
`_clear_current_transaction(using)`. This correctly restores nested context
without leaking state.

```python
# python/ormpi/transaction.py  (relevant excerpt)

async def __aenter__(self) -> Transaction:
    current = _get_current_transaction(self._using)
    if current is not None and current.is_open:
        self._is_nested = True
        self._txn = current
        self._savepoint_name = await _create_savepoint(current)
        self._ctx_token = None  # no ContextVar change for nested
    else:
        self._is_nested = False
        self._txn = await _begin(using=self._using)
        self._ctx_token = _set_current_transaction(self._using, self._txn)
    return self._txn

async def __aexit__(self, exc_type, exc_val, exc_tb):
    ...
    if not self._is_nested and self._ctx_token is not None:
        _reset_current_transaction(self._ctx_token)
    return False
```

**TC-5.1 — `_get_current_transaction` returns `None` outside any transaction**
```python
import asyncio
from ormpi._transaction_local import _get_current_transaction

def test_no_ambient_transaction_outside_atomic():
    # Run in a fresh event loop context
    async def inner():
        return _get_current_transaction("default")

    result = asyncio.run(inner())
    assert result is None
```

**TC-5.4 — `atomic()` clears ambient transaction after exception**

async def test_atomic_clears_ambient_on_exception():

**TC-5.5 — Child task does NOT inherit parent's ambient transaction**
```python
@pytest.mark.asyncio
async def test_child_task_isolation():
    """asyncio.create_task copies context; child must not share parent's txn."""
    from ormpi._transaction_local import _get_current_transaction
    import asyncio

    child_ambient = None

    async def child():
        nonlocal child_ambient
        child_ambient = _get_current_transaction("default")

    async with ormpi.transaction.atomic():
        # Child task is created while parent has an active transaction.
        # ContextVar copy-on-write means the child sees a snapshot that
        # includes the parent's key — but mutations in the child do NOT
        # flow back to the parent.
        task = asyncio.create_task(child())
        await task

    # Child should have seen the SNAPSHOT of the parent context at task
    # creation time, which included the transaction.
    # The critical property: if the child sets a new transaction, it does
    # NOT clobber the parent.
    # (This test verifies mutation isolation, not snapshot isolation)
    assert _get_current_transaction("default") is None  # parent cleaned up
```

**TC-5.6 — Nested `atomic()` restores outer transaction on exit**
```python
@pytest.mark.asyncio
async def test_nested_atomic_restores_outer():
    from ormpi._transaction_local import _get_current_transaction

    async with ormpi.transaction.atomic() as outer:
        async with ormpi.transaction.atomic() as inner:
            assert inner is outer  # same txn, nested uses savepoint

        # After inner exits, ambient is still the outer txn
        assert _get_current_transaction("default") is outer

    assert _get_current_transaction("default") is None
```

**TC-5.7 — No memory leak: no reference to task object after completion**
```python
import gc, weakref

@pytest.mark.asyncio
async def test_no_task_reference_leak():
    """ContextVar holds no reference to the task object."""
    ref = None

    async def body():
        nonlocal ref
        task = asyncio.current_task()
        ref = weakref.ref(task)
        async with ormpi.transaction.atomic():
            pass

    await body()
    gc.collect()
    # The task may or may not have been GC'd at this point depending on the
    # event loop; what we assert is that _CURRENT dict no longer exists /
    # doesn't hold the task.
    from ormpi import _transaction_local as tl
    assert not hasattr(tl, '_CURRENT'), \
        "_CURRENT dict must not exist; ContextVar-based impl expected"
```
