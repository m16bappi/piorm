# Task 5: Extract `find_children_matching` to Eliminate Duplicate FK-Walk Logic

## Problem

`ormpi-core/src/model/executor.rs` contains two nearly identical functions that walk the model registry looking for FK/O2O fields referencing a parent model:

```rust
// model/executor.rs lines 212–229
pub fn find_cascade_children(parent_model_name: &str) -> Vec<(ModelDef, String)> {
    let reg = ModelRegistry::global();
    let guard = reg.read().unwrap();
    let mut children = Vec::new();
    for child_def in guard.all() {
        for field in child_def.fields.values() {
            let (to, on_delete) = match &field.field_type {
                FieldType::ForeignKey { to, on_delete, .. } => (to.as_str(), on_delete),
                FieldType::OneToOne { to, on_delete }       => (to.as_str(), on_delete),
                _ => continue,
            };
            if to == parent_model_name && matches!(on_delete, OnDelete::Cascade) {
                children.push((child_def.clone(), field.attname.clone()));  // ← attname
            }
        }
    }
    children
}

// model/executor.rs lines 232–250
pub fn find_set_null_children(parent_model_name: &str) -> Vec<(ModelDef, String)> {
    let reg = ModelRegistry::global();
    let guard = reg.read().unwrap();
    let mut children = Vec::new();
    for child_def in guard.all() {
        for field in child_def.fields.values() {
            let (to, on_delete) = match &field.field_type {
                FieldType::ForeignKey { to, on_delete, .. } => (to.as_str(), on_delete),
                FieldType::OneToOne { to, on_delete }       => (to.as_str(), on_delete),
                _ => continue,
            };
            if to == parent_model_name && matches!(on_delete, OnDelete::SetNull) {
                children.push((child_def.clone(), field.column_name())); // ← column_name()
            }
        }
    }
    children
}
```

The only differences are:
1. The `OnDelete` variant matched (`Cascade` vs `SetNull`)
2. The name extracted from the field (`field.attname.clone()` vs `field.column_name()`)

There is also a dead `let _ = child_def;` on line 364 that was added to suppress a spurious warning — it doesn't suppress anything meaningful and should be removed.

## Fix

### Step 1 — Add a private `find_children_matching` helper

Insert before `find_cascade_children`:

```rust
/// Walk every model in the registry and collect (child_def, field_name) pairs
/// where the field is a FK/O2O referencing `parent_model_name` and the
/// `predicate` returns true for that field's `on_delete` policy.
///
/// `name_fn` extracts the column identifier to store alongside each child def.
fn find_children_matching(
    parent_model_name: &str,
    predicate: impl Fn(&OnDelete) -> bool,
    name_fn: impl Fn(&crate::fields::FieldDef) -> String,
) -> Vec<(ModelDef, String)> {
    let reg = ModelRegistry::global();
    let guard = reg.read().unwrap();
    let mut children = Vec::new();

    for child_def in guard.all() {
        for field in child_def.fields.values() {
            let (to, on_delete) = match &field.field_type {
                FieldType::ForeignKey { to, on_delete, .. } => (to.as_str(), on_delete),
                FieldType::OneToOne { to, on_delete }       => (to.as_str(), on_delete),
                _ => continue,
            };
            if to == parent_model_name && predicate(on_delete) {
                children.push((child_def.clone(), name_fn(field)));
            }
        }
    }
    children
}
```

### Step 2 — Rewrite the two public functions as one-liners

```rust
pub fn find_cascade_children(parent_model_name: &str) -> Vec<(ModelDef, String)> {
    find_children_matching(
        parent_model_name,
        |od| matches!(od, OnDelete::Cascade),
        |f| f.attname.clone(),
    )
}

pub fn find_set_null_children(parent_model_name: &str) -> Vec<(ModelDef, String)> {
    find_children_matching(
        parent_model_name,
        |od| matches!(od, OnDelete::SetNull),
        |f| f.column_name(),
    )
}
```

### Step 3 — Remove the spurious `let _ = child_def` line

In `delete_instance` (around line 364), remove:

```rust
// Before (line 361–365):
let set_null_children = find_set_null_children(&model_def.model_name);
for (child_def, fk_col) in &set_null_children {
    set_null_children_by_pk(pool, &backend, &child_def.table_name, fk_col, &pk_value).await?;
    let _ = child_def; // suppress unused warning   ← DELETE THIS LINE
}
```

The `let _ = child_def;` does not suppress any warning — `child_def` is already used on the line above. Remove it.
