# Task 1.1 — Initialize Cargo Workspace

## Objective
Create the Cargo workspace with three member crates and configure all base dependencies. The workspace must compile cleanly with `cargo check`.

## Files to Create

### `/Cargo.toml` (workspace root)
```toml
[workspace]
resolver = "2"
members = [
    "ormpi-core",
    "ormpi-py",
    "ormpi-cli",
]

[workspace.dependencies]
# Shared versions to keep consistent
sqlx            = { version = "0.8", features = ["runtime-tokio", "sqlite", "mysql", "postgres", "chrono", "uuid", "json"] }
sea-query       = { path = "sea-query", features = [
                    "backend-sqlite", "backend-mysql", "backend-postgres",
                    "with-chrono", "with-uuid", "with-json", "derive" ] }
tokio           = { version = "1", features = ["full"] }
serde           = { version = "1", features = ["derive"] }
serde_json      = "1"
thiserror       = "1"
once_cell       = "1"
pyo3            = { version = "0.22", features = ["extension-module", "abi3-py39"] }
pyo3-async-runtimes = { version = "0.22", features = ["tokio-runtime"] }
clap            = { version = "4", features = ["derive", "color"] }
tracing         = "0.1"
tracing-subscriber = { version = "0.3", features = ["env-filter"] }
```

### `ormpi-core/Cargo.toml`
```toml
[package]
name = "ormpi-core"
version = "0.1.0"
edition = "2021"

[dependencies]
sqlx.workspace = true
sea-query.workspace = true
tokio.workspace = true
serde.workspace = true
serde_json.workspace = true
thiserror.workspace = true
once_cell.workspace = true
tracing.workspace = true
chrono = { version = "0.4", features = ["serde"] }
uuid = { version = "1", features = ["v4", "serde"] }
indexmap = "2"
```

### `ormpi-py/Cargo.toml`
```toml
[package]
name = "ormpi-py"
version = "0.1.0"
edition = "2021"

[lib]
name = "ormpi"
crate-type = ["cdylib"]

[dependencies]
ormpi-core = { path = "../ormpi-core" }
pyo3.workspace = true
pyo3-async-runtimes.workspace = true
tokio.workspace = true
tracing.workspace = true
tracing-subscriber.workspace = true
```

### `ormpi-cli/Cargo.toml`
```toml
[package]
name = "ormpi-cli"
version = "0.1.0"
edition = "2021"

[[bin]]
name = "ormpi-cli"
path = "src/main.rs"

[dependencies]
ormpi-core = { path = "../ormpi-core" }
pyo3.workspace = true
clap.workspace = true
tokio.workspace = true
tracing.workspace = true
tracing-subscriber.workspace = true
serde.workspace = true
serde_json.workspace = true
```

## Stub Source Files to Create

Create minimal `src/lib.rs` (or `src/main.rs`) for each crate so `cargo check` passes:

- `ormpi-core/src/lib.rs` — empty `pub mod` stubs
- `ormpi-py/src/lib.rs` — `#[pyo3::pymodule] fn ormpi(_py: Python, _m: &PyModule) -> PyResult<()> { Ok(()) }`
- `ormpi-cli/src/main.rs` — `fn main() {}`

## Acceptance Criteria
- [x] `cargo check --workspace` exits 0 with no errors
- [x] `cargo build --workspace` compiles all three crates
- [x] No unused dependency warnings for core deps
- [x] Workspace dependency deduplication works (single version of sqlx, pyo3)
