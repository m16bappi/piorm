# Task 1.3 — DatabaseBackend Enum & Query Builder Dispatch

## Objective
Implement the `DatabaseBackend` enum and a `QueryBackend` wrapper that dispatches sea-query statement building to the correct backend. This is the central abstraction that makes all query generation backend-agnostic.

## Location
`ormpi-core/src/backend.rs`

## Implementation

### DatabaseBackend Enum
```rust
use sea_query::{
    MysqlQueryBuilder, PostgresQueryBuilder, SqliteQueryBuilder,
    SchemaStatementBuilder, QueryStatementBuilder,
    SelectStatement, InsertStatement, UpdateStatement, DeleteStatement,
    TableCreateStatement, TableAlterStatement, TableDropStatement,
    IndexCreateStatement, IndexDropStatement,
    ForeignKeyCreateStatement, ForeignKeyDropStatement,
    Values,
};

/// The three supported SQL dialects.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum DatabaseBackend {
    Sqlite,
    Mysql,
    Postgres,
}

impl DatabaseBackend {
    /// Parse from ENGINE string (supports multiple aliases).
    pub fn from_engine(engine: &str) -> crate::Result<Self> {
        match engine.to_lowercase().as_str() {
            "sqlite" | "sqlite3" | "ormpi.backends.sqlite" => Ok(Self::Sqlite),
            "mysql" | "mariadb" | "ormpi.backends.mysql" => Ok(Self::Mysql),
            "postgres" | "postgresql" | "ormpi.backends.postgres" | "ormpi.backends.postgresql"
                => Ok(Self::Postgres),
            other => Err(crate::OrmpiError::UnknownBackend(other.to_string())),
        }
    }

    /// Returns the placeholder style used in parameterized queries.
    /// SQLite/MySQL use `?`, Postgres uses `$1, $2, ...`
    pub fn placeholder_style(&self) -> PlaceholderStyle {
        match self {
            Self::Postgres => PlaceholderStyle::Numbered,
            _              => PlaceholderStyle::QuestionMark,
        }
    }
}

#[derive(Debug, Clone, Copy)]
pub enum PlaceholderStyle {
    QuestionMark,   // ? (MySQL, SQLite)
    Numbered,       // $1, $2, $3 (Postgres)
}
```

### QueryBackend — DML Dispatch
```rust
/// Wraps sea-query builders to provide a unified interface.
#[derive(Debug, Clone, Copy)]
pub struct QueryBackend(pub DatabaseBackend);

impl QueryBackend {
    pub fn build_select(&self, stmt: &SelectStatement) -> (String, Values) {
        match self.0 {
            DatabaseBackend::Sqlite   => stmt.build(SqliteQueryBuilder),
            DatabaseBackend::Mysql    => stmt.build(MysqlQueryBuilder),
            DatabaseBackend::Postgres => stmt.build(PostgresQueryBuilder),
        }
    }

    pub fn build_insert(&self, stmt: &InsertStatement) -> (String, Values) {
```

### Values → sqlx Compatible Binding

sea-query returns `Values` (a `Vec<sea_query::Value>`). We need to convert these to sqlx `Arguments`. Write a helper:

```rust

pub fn bind_values_sqlite<'q>(
    query: sqlx::query::Query<'q, sqlx::Sqlite, sqlx::sqlite::SqliteArguments<'q>>,
    values: &'q Values,

    let mut q = query;
```

## Unit Tests

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use sea_query::{Query, Expr};

    #[test]
    fn test_sqlite_select() {
        let (sql, _values) = QueryBackend(DatabaseBackend::Sqlite)
            .build_select(&Query::select()
                .column(sea_query::Asterisk)
                .from_raw_sql("users")
                .and_where(Expr::col(sea_query::Alias::new("id")).eq(1))
                .to_owned());
        assert!(sql.contains("WHERE"));
        assert!(sql.contains('"'));  // SQLite uses double-quotes
    }

    #[test]
    fn test_from_engine_aliases() {
        assert_eq!(DatabaseBackend::from_engine("sqlite").unwrap(), DatabaseBackend::Sqlite);
        assert_eq!(DatabaseBackend::from_engine("POSTGRES").unwrap(), DatabaseBackend::Postgres);
        assert_eq!(DatabaseBackend::from_engine("mariadb").unwrap(), DatabaseBackend::Mysql);
        assert!(DatabaseBackend::from_engine("oracle").is_err());
    }
}
```
