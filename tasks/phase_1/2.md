# Task 1.2 — Maturin Build System & Python Package Scaffold

## Objective
Set up `maturin` as the build backend, create `pyproject.toml`, and establish the Python package skeleton so that `maturin develop` installs a working `import ormpi`.

## Files to Create

### `pyproject.toml`
```toml
[build-system]
requires = ["maturin>=1.7,<2.0"]
build-backend = "maturin"

[project]
name = "ormpi"
version = "0.1.0"
description = "A Django-like async ORM for Python, built on Rust (sea-query + sqlx)"
readme = "README.md"
license = { text = "MIT OR Apache-2.0" }
requires-python = ">=3.9"
keywords = ["orm", "database", "async", "sqlite", "postgres", "mysql", "rust"]

    "Development Status :: 3 - Alpha",
    "Intended Audience :: Developers",
    "Topic :: Database",
    "Framework :: AsyncIO",
    "Programming Language :: Python :: 3",
    "Programming Language :: Rust",
]

[project.scripts]
ormpi = "ormpi._cli:main"

[project.optional-dependencies]
test = [
    "pytest>=8.0",
    "pytest-asyncio>=0.23",
    "anyio[trio]",
]

    "mypy>=1.10",
    "pyright>=1.1",

"""Console script entry point for the ormpi CLI."""
import sys

def main() -> int:
    try:
        from ormpi._core import run_cli
        return run_cli(sys.argv[1:])
    except ImportError:
        print("ormpi CLI not available in this build.", file=sys.stderr)
        return 1

if __name__ == "__main__":
    sys.exit(main())
```
