# Task 14.2 — `models.py` + `models.pyi`: `__slots__` + Bitmask `__setattr__`

## Objective

Rewrite `python/ormpi/models.py` to use `__slots__` instead of `__dict__`, replace the
`_ormpi_dirty` set with an integer bitmask `_dirty`, flatten `_ormpi_state` into two
scalar slots (`_adding`, `_db`), and rename `_ormpi_values` → `_values`. Update
`models.pyi` to reflect the new private-attribute layout.

**Prerequisite:** Task 14.1 must be complete. `_field_bits` must already be set on each
model class at registration time before `__setattr__` can use it.

---

## `python/ormpi/models.py` — full rewrite

```python
"""
Python-level Model base class.

Wraps the Rust `_core.Model` (which provides the Rust-side struct) and
adds Python-friendly `__init__`, `__init_subclass__`, `__getattr__`,
`__setattr__`, and `DoesNotExist`.

Registration into the global `ModelRegistry` is done by the Rust function
`_register_model_class`, called explicitly from `__init_subclass__`.
"""

__all__ = ["Model"]

from typing import Any, ClassVar

from ormpi._core import Model as _BaseModel
from ormpi._core import _register_model_class
from ormpi.exceptions import DoesNotExist


class Model(_BaseModel):
    """Base class for all ormpi model definitions.

    Subclass this to define a database model::

        from ormpi.models import Model
        from ormpi.fields import CharField, IntegerField

        class Article(Model):
            title = CharField(max_length=200)
            views = IntegerField(default=0)

    Each concrete subclass is automatically registered in the global
    ``ModelRegistry`` and given an ``objects`` manager.
    """

    # ── Slot layout ──────────────────────────────────────────────────────
    #
    # Five slots replace the old __dict__ + 3 dicts/sets:
    #
    #   _values   dict[str, Any]   field values (was _ormpi_values)
    #   _dirty    int              bitmask of modified fields (was _ormpi_dirty set)
    #   _adding   bool             True until first successful save() (was _ormpi_state["adding"])
    #   _db       str | None       alias used for last save (was _ormpi_state["db"])
    #   __weakref__                required by __slots__ for weakref support
    #
    # _field_bits is a ClassVar dict[str, int] set by _register_model_class (Task 14.1).
    # It maps field name → power-of-two bit used in the _dirty bitmask.
    __slots__ = ("_values", "_dirty", "_adding", "_db", "__weakref__")

    _field_bits: ClassVar[dict[str, int]]

    # ── Construction ─────────────────────────────────────────────────────

    def __init__(self, **kwargs: Any) -> None:
        self._values: dict[str, Any] = {}
        self._dirty: int = 0
        self._adding: bool = True
        self._db: str | None = None
        for k, v in kwargs.items():
            setattr(self, k, v)

    # ── Subclass registration ─────────────────────────────────────────────

    def __init_subclass__(cls, **kwargs: Any) -> None:
        super().__init_subclass__(**kwargs)

        # Skip abstract models — check only this class's own Meta, not inherited.
        own_meta = cls.__dict__.get("Meta", None)
        if own_meta and getattr(own_meta, "abstract", False):
            return

        # Register fields + build ModelDef in Rust, attach `objects` manager,
        # and set _field_bits on the class (Task 14.1).
        _register_model_class(cls)

        # Attach a model-specific DoesNotExist exception.
        cls.DoesNotExist = type(
            "DoesNotExist",
            (DoesNotExist,),
            {"__module__": cls.__module__},
        )

    # ── Descriptor protocol ───────────────────────────────────────────────

    def __getattr__(self, name: str) -> Any:
        """Fall through to _values for field reads.

        Called only when normal attribute lookup (slots + class dict) fails,
        i.e. only for field names that are not slots.
        """
        # Avoid infinite recursion if _values itself is not yet initialised
        # (can happen during __init__ before the first assignment).
        if name == "_values":
            raise AttributeError(name)
        try:
            return self._values[name]
        except KeyError:
            raise AttributeError(
                f"'{type(self).__name__}' object has no attribute '{name}'"
            ) from None

    def __setattr__(self, name: str, value: Any) -> None:
        """Route writes to slots or to _values + dirty bitmask.

        Slot names are handled by object.__setattr__ directly.
        Everything else is a field write: stored in _values and the
        corresponding bit is OR-ed into _dirty.
        """
        if name in ("_values", "_dirty", "_adding", "_db"):
            object.__setattr__(self, name, value)
            return

        # Field write — store value and mark field dirty.
        self._values[name] = value
        bit = self.__class__.__dict__.get("_field_bits", {}).get(name, 0)
        if bit:
            self._dirty |= bit

    # ── Properties ───────────────────────────────────────────────────────

    @property
    def pk(self) -> Any:
        """Return the primary-key value for the field that has primary_key=True."""
        pk_field = getattr(self.__class__, "_ormpi_pk_field", "id")
        return self._values.get(pk_field)

    # ── Repr ──────────────────────────────────────────────────────────────

    def __repr__(self) -> str:
        pk_field = getattr(self.__class__, "_ormpi_pk_field", "id")
        pk = self._values.get(pk_field, "?")
        return f"<{self.__class__.__name__}: pk={pk}>"

    # ── Abstract base ─────────────────────────────────────────────────────

    class Meta:
        abstract = True
```

## `__setattr__` design notes

### Why `object.__setattr__` for slot names?

Without this guard, assigning `self._values = {}` inside `__init__` would recurse back
into our `__setattr__`, which tries to read `self._values` — which doesn't exist yet —
causing an infinite loop or `AttributeError`. The guard short-circuits slot assignments
to the C-level `object.__setattr__`, which writes directly into the slot.

### Why `self.__class__.__dict__.get("_field_bits", {})`?

`__class__.__dict__` is checked directly (not `getattr`) to avoid triggering `__getattr__`
on the class. Using `getattr(self.__class__, "_field_bits", {})` would also work, but
direct `__dict__` access is marginally faster and avoids descriptor protocol overhead on
the class lookup. An empty dict fallback is safe: it means the bit is 0, the `if bit:`
guard skips the bitmask update, and the value is still stored in `_values`.

### `__getattr__` is only called on miss

Python calls `__getattr__` only after the normal attribute lookup chain fails. Normal
lookup checks: instance slots → class dict → base class dicts. Because `_values`,
`_dirty`, `_adding`, `_db` are in `__slots__`, they are found in the first step and never
reach `__getattr__`. Field names like `title` or `views` are not slots, so they fall
through to `__getattr__` → `_values[name]`. This is intentional and correct.

## Pickling Note

`__slots__` without `__dict__` requires explicit `__getstate__` / `__setstate__` for
pickling to work. Pickle support is not in scope for Phase 14 and ormpi does not
currently support pickling. Add a note in the class docstring:

```python
# Note: pickling model instances is not supported. Use .values() queries
# or serialize via your own __getstate__ / __setstate__ if needed.
```

---

## Subclass opt-in to dynamic attributes

Users who need to attach arbitrary extra attributes to a model instance can opt in by
declaring `__slots__ = ("__dict__",)` in their subclass:

```python
class MyModel(Model):
    __slots__ = ("__dict__",)   # re-adds __dict__ for this subclass only
    name = CharField(max_length=100)
```

This is a deliberate design choice — opt-in overhead rather than opt-out savings.

## Files NOT Changed

are updated in Tasks 14.3 and 14.4. Until those tasks are complete, the Rust layer writes
`_ormpi_values` as a setattr but Python no longer has `_ormpi_values` as a slot or dict
key — this will cause a `AttributeError` on slot write. For this reason Tasks 14.2, 14.3,
and 14.4 should be implemented together in a single branch before any test run.
