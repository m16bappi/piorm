# Task 12.2 — Python 3.12+ Stubs Rewrite

## Objective

Rewrite every `.pyi` file in `python/ormpi/` to use Python 3.12+ type system features.
Remove all `from __future__ import annotations`, replace `TypeVar("M", ...)` with PEP 695
`[M]` syntax, replace `Union[X, Y]` with `X | Y`, use `type X = ...` for aliases, apply
`@override`, `LiteralString`, `dataclass_transform`, and `Protocol` correctly.

---

## Python 3.12+ Features Used

| Feature | PEP | Example |
|---------|-----|---------|
| Generic classes with `[T]` | PEP 695 | `class QuerySet[M]:` |
| Generic functions with `[T]` | PEP 695 | `def get[M](self) -> M:` |
| `type` alias statement | PEP 695 | `type Alias = dict[str, Any]` |
| `override` decorator | PEP 698 | `@override def __repr__` |
| `LiteralString` | PEP 675 | `sql: LiteralString` |
| `Never` | PEP 673 | `def assert_never(x: Never) -> Never:` |
| `Self` | PEP 673 | `def filter(self, ...) -> Self:` |
| `TypeIs` | PEP 742 (3.13) → use `TypeGuard` for 3.12 compat | `def is_model(x) -> TypeGuard[Model]:` |
| `dataclass_transform` | PEP 681 | On `ModelMeta` for IDE field inference |
| `Unpack` + `TypedDict` | PEP 692 | Typed `**kwargs` for `filter()` |
| `@final` | PEP 591 | `@final class Transaction:` |
