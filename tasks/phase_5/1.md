# Task 5.1 — DATABASES Config Parsing & Multi-Pool Initialization

## Objective
Implement full `DATABASES` configuration parsing from a Python dict, pool creation for all aliases simultaneously, and the `connections` / `connection` API for accessing pools.

## Location
`ormpi-core/src/config.rs` (updated)
`ormpi-py/src/db/connections.rs`

## Enhanced configure() Function

```rust
#[pyfunction]
fn configure<'py>(
    py: Python<'py>,
    databases: HashMap<String, HashMap<String, PyObject>>,
    database_routers: Option<Vec<String>>,
    default_auto_field: Option<String>,
    installed_apps: Option<Vec<String>>,
) -> PyResult<&'py PyAny> {
    // 1. Parse all DatabaseConfig structs
    let configs: Vec<DatabaseConfig> = databases.iter()
        .map(|(alias, config_map)| {
            let json_map = py_dict_to_json_map(py, config_map)?;
            DatabaseConfig::from_map(alias, &json_map)
        })
        .collect::<Result<_>>()?;

    // 2. Validate: "default" alias required
    if !configs.iter().any(|c| c.alias == "default") {
        return Err(PyValueError::new_err("DATABASES must contain a 'default' entry"));
    }

    // 3. Parse router module paths
    let router_paths = database_routers.unwrap_or_default();

    pyo3_async_runtimes::tokio::future_into_py(py, async move {
        // Create all pools concurrently
        let pool_futures: Vec<_> = configs.iter()
            .map(|c| OrmpiPool::connect(c))
            .collect();

        let pools = futures::future::try_join_all(pool_futures).await?;

        // Store in registry
        let mut registry_guard = DatabaseRegistry::global().write().unwrap();
        registry_guard.pools.clear();
        registry_guard.configs.clear();
        for (config, pool) in configs.iter().zip(pools) {
            registry_guard.pools.insert(config.alias.clone(), pool);
            registry_guard.configs.insert(config.alias.clone(), config.clone());
        }

        // Store router configuration
        ROUTER_CHAIN.store(Arc::new(router_paths));

        Ok(())
    })
}
```

## connections / connection API

```rust
// ormpi-py/src/db/connections.rs

/// A DatabaseWrapper gives Python code access to a specific pool.
#[pyclass(name = "DatabaseWrapper")]
pub struct PyDatabaseWrapper {
    pub alias: String,
}

#[pymethods]
impl PyDatabaseWrapper {
    /// Execute a raw SQL query (for advanced users).
    fn execute<'py>(&self, py: Python<'py>, sql: String, params: Option<Vec<PyObject>>) -> PyResult<&'py PyAny> {
        let alias = self.alias.clone();
        pyo3_async_runtimes::tokio::future_into_py(py, async move {
            let registry = DatabaseRegistry::global().read().unwrap();
            let pool = registry.get_pool(&alias)?;
            let params: Vec<OrmpiValue> = py_params_to_ormpi(params)?;
            let rows = execute_raw_with_params(pool, &sql, &params).await?;
            Ok(rows)
        })
    }

    #[getter]
    fn vendor(&self) -> PyResult<String> {
        let registry = DatabaseRegistry::global().read().unwrap();
        let config = registry.get_config(&self.alias)?;
        Ok(match config.backend {
            DatabaseBackend::Sqlite   => "sqlite".to_string(),
            DatabaseBackend::Mysql    => "mysql".to_string(),
            DatabaseBackend::Postgres => "postgresql".to_string(),
        })
    }

    #[getter]
    fn alias(&self) -> &str { &self.alias }
}

/// A proxy that resolves the alias at access time.
#[pyclass(name = "ConnectionProxy")]
pub struct PyConnectionProxy;

#[pymethods]
impl PyConnectionProxy {
    fn __getitem__(&self, alias: String) -> PyResult<PyDatabaseWrapper> {
        // Verify alias exists
        let registry = DatabaseRegistry::global().read().unwrap();
        registry.get_pool(&alias)?;   // raises if not found
        Ok(PyDatabaseWrapper { alias })
    }

    fn __contains__(&self, alias: String) -> bool {
        let registry = DatabaseRegistry::global().read().unwrap();
        registry.pools.contains_key(&alias)
    }

    fn all_aliases(&self) -> Vec<String> {
        let registry = DatabaseRegistry::global().read().unwrap();
        registry.pools.keys().cloned().collect()
    }
}
```

## close() Utility

```rust
#[pyfunction]
fn close<'py>(py: Python<'py>) -> PyResult<&'py PyAny> {
    pyo3_async_runtimes::tokio::future_into_py(py, async move {
        let registry = DatabaseRegistry::global().read().unwrap();
        let close_futures: Vec<_> = registry.pools.values().map(|p| p.close()).collect();
        futures::future::join_all(close_futures).await;
        Ok(())
    })
}
```

```rust
/// For testing: creates an in-memory SQLite pool for all aliases.
pub async fn setup_test_databases(test_aliases: &[String]) -> Result<()> {
    let mut registry = DatabaseRegistry::global().write().unwrap();
    for alias in test_aliases {
        let test_config = DatabaseConfig {
            alias: alias.clone(),
            backend: DatabaseBackend::Sqlite,
            name: ":memory:".to_string(),
            ..Default::default()
        };
        let pool = OrmpiPool::connect(&test_config).await?;
        registry.pools.insert(alias.clone(), pool);
        registry.configs.insert(alias.clone(), test_config);
    }
    Ok(())
}
```

## Acceptance Criteria
- [ ] `await ormpi.configure({"default": {...}, "replica": {...}})` creates two pools
- [ ] Concurrent pool creation (both connect simultaneously, not sequentially)
- [ ] Missing "default" raises `ValueError`
- [ ] `connections["default"].vendor` returns correct backend string
- [ ] `connections["nonexistent"]` raises `OrmpiError::UnknownDatabase`
- [ ] `"default" in connections` returns True
- [ ] `await ormpi.close()` gracefully closes all pools
- [ ] Pool options (`max_connections`, `connect_timeout`) applied from config
