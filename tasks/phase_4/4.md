# Task 4.4 — select_related, prefetch_related & bulk_create/bulk_update

## Objective
Implement JOIN-based `select_related()` for FK/O2O relations (single query), and batch-fetch-based `prefetch_related()` for reverse FK and M2M relations. Also implement `bulk_create()` and `bulk_update()` for efficient batch operations.

## select_related Implementation

`select_related` issues a single SQL query with LEFT JOINs for each specified related model.

```rust
// ormpi-core/src/query/join.rs

pub fn apply_select_related(
    stmt: &mut SelectStatement,
    base_model: &ModelDef,
    related_paths: &[String],   // e.g., ["author", "category", "author__profile"]
    registry: &ModelRegistry,
) -> Result<()> {
    for path in related_paths {
        let parts: Vec<&str> = path.split("__").collect();
        let mut current_model = base_model;
        let mut join_alias_prefix = current_model.table_name.clone();

        for field_name in parts {
            let field = current_model.fields.get(field_name)
                .ok_or_else(|| OrmpiError::UnknownField {
                    keyword: field_name.to_string(),
                    choices: current_model.fields.keys().cloned().collect::<Vec<_>>().join(", "),
                })?;

            match &field.field_type {
                FieldType::ForeignKey { to, .. } | FieldType::OneToOne { to, .. } => {
                    let related_model = registry.get_by_name(to)
                        .ok_or_else(|| OrmpiError::UnknownDatabase(to.clone()))?;

                    let join_alias = format!("{}_{}", join_alias_prefix, field_name);

                    // Add all columns from related model with alias prefix
                    for rel_field in related_model.fields.values() {
                        let aliased_col = format!("{}__{}", field_name, rel_field.attname);
                        stmt.expr_as(
                            Expr::col((Alias::new(&related_model.table_name), Alias::new(&rel_field.column_name()))),
                            Alias::new(&aliased_col),
                        );
                    }

                    // Add LEFT JOIN
                    stmt.left_join(
                        Alias::new(&related_model.table_name),
                        Expr::col((Alias::new(&current_model.table_name), Alias::new(&field.column_name())))
                            .equals((Alias::new(&related_model.table_name), Alias::new(&related_model.pk_field)))
                    );

                    current_model = related_model;
                    join_alias_prefix = join_alias;
                }
                _ => return Err(OrmpiError::FieldError {
                    model: current_model.model_name.clone(),
                    field: field_name.to_string(),
                    message: "select_related can only follow ForeignKey/OneToOneField".to_string(),
                }),
            }
        }
    }
    Ok(())
}
```

### Result Hydration

After fetching rows with JOINs, split each row into the base model instance and related model instances:

```rust
pub fn hydrate_select_related(
    py: Python<'_>,
    rows: Vec<OrmpiRow>,
    base_model: &ModelDef,
    related_paths: &[String],
    registry: &ModelRegistry,
) -> PyResult<Vec<PyObject>> {
    rows.into_iter().map(|row| {
        // Build base instance from non-prefixed columns
        let instance = build_model_instance(py, &row, base_model)?;

        // Build related instances from prefixed columns, cache on instance
        for path in related_paths {
            let prefixed_row = extract_prefixed_columns(&row, &format!("{}_", path));
            let rel_model = resolve_model_for_path(path, base_model, registry)?;
            let rel_instance = build_model_instance(py, &prefixed_row, rel_model)?;
            let cache_key = format!("_ormpi_cache_{}", path);
            instance.as_ref(py).setattr(cache_key.as_str(), rel_instance)?;
        }

        Ok(instance)
    }).collect()
}
```

## prefetch_related Implementation

Issues N+1 queries where N = number of distinct related models.

```rust
pub async fn apply_prefetch_related(
    py: Python<'_>,
    instances: Vec<PyObject>,
    prefetch_lookups: &[String],
    base_model: &ModelDef,
    registry: &ModelRegistry,
    pool: &OrmpiPool,
    backend: QueryBackend,
) -> Result<Vec<PyObject>> {
    for lookup in prefetch_lookups {
        // Collect all PKs from base instances
        let pk_vals: Vec<OrmpiValue> = instances.iter().map(|inst| {
            Python::with_gil(|py| {
                let values = inst.as_ref(py).getattr("_ormpi_values")?;
                let pk = values.get_item(&base_model.pk_field)?;
                py_to_ormpi_value(py, pk)
            })
        }).collect::<Result<_>>()?;

        // Resolve the field: FK reverse or M2M
        // Build: SELECT * FROM related_table WHERE base_fk_id IN (pk_vals...)
        let rel_stmt = Query::select()
            .from(Alias::new(&related_table))
            .expr(Expr::asterisk())
            .and_where(Expr::col(Alias::new(&fk_col)).is_in(
                pk_vals.iter().map(|v| v.to_sea_value()).collect::<Vec<_>>()
            ))
            .to_owned();

        let (sql, values) = backend.build_select(&rel_stmt);
        let rel_rows = execute_rows(pool, &sql, &values).await?;

        // Group by FK column, attach to base instances
        let mut grouped: HashMap<OrmpiValue, Vec<OrmpiRow>> = HashMap::new();
        for row in rel_rows {
            let fk_val = row.get(&fk_col).cloned().unwrap_or(OrmpiValue::Null);
            grouped.entry(fk_val).or_default().push(row);
        }

        // Set prefetch cache on each instance
        Python::with_gil(|py| {
            for inst in &instances {
                let inst_ref = inst.as_ref(py);
                let pk = get_instance_pk(py, inst_ref)?;
                let related_rows = grouped.get(&pk).cloned().unwrap_or_default();
                let rel_instances: Vec<_> = related_rows.into_iter()
                    .map(|r| build_model_instance(py, &r, &rel_model_def))
                    .collect::<PyResult<_>>()?;
                let cache = PyList::new(py, rel_instances);
                inst_ref.setattr(format!("_prefetch_cache_{}", lookup).as_str(), cache)?;
            }
            Ok::<_, OrmpiError>(())
        })?;
    }

    Ok(instances)
}
```

## bulk_create()

```rust
fn bulk_create<'py>(
    slf: &'py PyAny, py: Python<'py>,
    objs: Vec<PyObject>,
    batch_size: Option<usize>,
) -> PyResult<&'py PyAny> {
    let state = get_state(slf)?.clone();
    let batch = batch_size.unwrap_or(1000);

    pyo3_async_runtimes::tokio::future_into_py(py, async move {
        let pool = get_pool(&state)?;
        let backend = QueryBackend(pool.backend());
        let model_def = get_model_def(&state)?;

        // Split into batches
        for chunk in objs.chunks(batch) {
            let mut stmt = Query::insert()
                .into_table(Alias::new(&model_def.table_name))
                .to_owned();

            let insert_fields: Vec<&FieldDef> = model_def.fields.values()
                .filter(|f| !f.primary_key && !matches!(f.field_type, FieldType::ManyToMany { .. }))
                .collect();

            stmt.columns(insert_fields.iter().map(|f| Alias::new(&f.column_name())));

            for obj in chunk {
                let values = Python::with_gil(|py| {
                    let values_dict = obj.as_ref(py).getattr("_ormpi_values")?;
                    insert_fields.iter().map(|f| {
                        let v = values_dict.get_item(&f.attname)?;
                        py_to_ormpi_value(py, v)
                    }).collect::<PyResult<Vec<_>>>()
                })?;
                stmt.values_panic(values.iter().map(|v| Expr::val(v.to_sea_value())));
            }

            let (sql, sea_vals) = backend.build_insert(&stmt);
            execute_affecting(pool, &sql, &sea_vals).await?;
        }
        Ok(())
    })
}
```

## bulk_update()

```rust
fn bulk_update<'py>(
    slf: &'py PyAny, py: Python<'py>,
    objs: Vec<PyObject>,
    fields: Vec<String>,
    batch_size: Option<usize>,
) -> PyResult<&'py PyAny> {
    // For each batch: issue N individual UPDATEs or a single
    // UPDATE ... SET ... WHERE pk IN (...) CASE WHEN pattern
    // Simple implementation: N individual UPDATEs per object
    pyo3_async_runtimes::tokio::future_into_py(py, async move {
        for obj in &objs {
            let pk = get_py_pk(obj)?;
            let updates = get_field_values(obj, &fields)?;
            // build UPDATE ... WHERE pk = {pk}
            execute_single_update(pool, backend, model_def, pk, updates).await?;
        }
        Ok(objs.len() as i64)
    })
}
```

## Acceptance Criteria
- [x] `select_related("author")` results in a JOIN, not N+1 queries
- [x] Nested `select_related("author__profile")` joins two levels
- [x] `prefetch_related("articles")` issues exactly 2 queries
- [x] Prefetched results accessible as `author._prefetch_cache_articles`
- [x] `bulk_create([...])` inserts all objects in batches
- [x] `bulk_create` respects `batch_size` parameter
- [x] `bulk_update(objs, ["title"])` updates only the `title` field
- [x] None FK value results in NULL in JOIN (LEFT JOIN)
