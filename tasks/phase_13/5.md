# Task 13.5 — `EvaluatedQuerySet[M]`: Two-Class QuerySet Model

## Supersedes

This task refines the `__await__` design from **Task 13.4**.
Task 13.4 changed `__await__` to return `QuerySet[M]` (was `list[M]`) and added the sync
collection protocol directly onto `QuerySet`. That fixed chaining after `await` and
`len(results)` / `for r in results`, but left one problem unsolved:

```python
results = await Author.objects.filter(name="Alice")
# results: QuerySet[Author]

results[0].name   # ✗  ERROR — results[0] is Coroutine[Any, Any, Author]
                  #          Attribute "name" is unknown on Coroutine
```

`QuerySet.__getitem__(int)` returns `Coroutine[Any, Any, M]` because that is the correct
type for an *unevaluated* queryset — `qs[0]` has to hit the database.  After `await`,
however, all rows are cached; `results[0]` should return `Author` synchronously, exactly
like Django's synchronous queryset does.

Task 13.4 used a single `QuerySet[M]` class for both states, which meant
`__getitem__(int)` had to serve both cases with the same return type — impossible.

---

## Root cause

A single class cannot express two different behaviours for `__getitem__(int)`:

| State | `qs[0]` runtime behaviour | Correct return type |
|-------|--------------------------|---------------------|
| Unevaluated | Fetches from DB (async) | `Coroutine[Any, Any, M]` |
| Evaluated (post-`await`) | Returns from cache (sync) | `M` |

The type system needs two distinct types.

---

## Solution: `QuerySet[M]` + `EvaluatedQuerySet[M]`

Django-stubs solves the analogous problem by having `QuerySet.__getitem__(int)` always
return the row type directly (Django is synchronous, so no coroutine needed). For ormpi
the same principle applies — after `await` the queryset behaves synchronously.

The design mirrors this with two classes:

```
QuerySet[M]            — lazy/unevaluated; __getitem__(int) → Coroutine[Any, Any, M]
    │
    └─ EvaluatedQuerySet[M]   — post-await; __getitem__(int) → M
                                also adds __iter__, __len__, __bool__, __contains__
```

`__await__` on `QuerySet[M]` returns `EvaluatedQuerySet[M]`, not `QuerySet[M]`.

---

## Class design

### `QuerySet[M]` — unchanged from Task 13.3 except `__await__` return type

```python
class QuerySet[M]:
    # ... all chainable methods return QuerySet[M] (unchanged)

    def __aiter__(self) -> AsyncIterator[M]: ...

    # ← KEY CHANGE from Task 13.4: returns EvaluatedQuerySet, not QuerySet
    def __await__(self) -> Generator[Any, None, EvaluatedQuerySet[M]]: ...

    def iterator(self, chunk_size: int = 2000) -> AsyncIterator[M]: ...

    # Integer index on unevaluated queryset is async (fetches from DB)
    @overload
    def __getitem__(self, key: int) -> Coroutine[Any, Any, M]: ...
    @overload
    def __getitem__(self, key: slice) -> QuerySet[M]: ...

    # Terminal async — unchanged
    def get(self, ...) -> Coroutine[Any, Any, M]: ...
    # ...
```

### `EvaluatedQuerySet[M]` — new class

```python
class EvaluatedQuerySet[M](QuerySet[M]):
    """QuerySet with rows fetched and cached.  Returned by ``await qs``.

    Integer indexing returns model instances directly (no ``await`` needed).
    Slicing returns another ``EvaluatedQuerySet`` (sub-range of the cache).
    All chainable methods (``filter``, ``exclude``, etc.) return a new
    *unevaluated* ``QuerySet[M]`` because re-filtering requires a new DB round-trip.

    Examples::

        results = await Author.objects.filter(active=True)
        # results: EvaluatedQuerySet[Author]

        results[0]              # Author  — no await needed
        results[0].name         # str     — attribute access works
        results[0:3]            # EvaluatedQuerySet[Author]
        len(results)            # int
        for r in results: ...   # r: Author
        "Alice" in [r.name for r in results]  # bool
        await results.filter(age__gte=30)     # EvaluatedQuerySet[Author]
    """

    # Override __getitem__: integer access is now synchronous
    @overload  # type: ignore[override]
    def __getitem__(self, key: int) -> M: ...
    @overload
    def __getitem__(self, key: slice) -> EvaluatedQuerySet[M]: ...

    # Synchronous collection protocol
    def __iter__(self)               -> Iterator[M]: ...
    def __len__(self)                -> int: ...
    def __bool__(self)               -> bool: ...
    def __contains__(self, item: object) -> bool: ...
    def __reversed__(self)           -> Iterator[M]: ...
```

---

## Why `# type: ignore[override]` on `__getitem__`

`EvaluatedQuerySet` overrides `QuerySet.__getitem__(int)` with a narrower return type
(`M` instead of `Coroutine[Any, Any, M]`). This is technically a Liskov substitution
violation — `M` is not a subtype of `Coroutine[Any, Any, M]` in general.

In practice, however, the override is safe: once a queryset is evaluated its rows are
cached; there is no async operation for `qs[0]`. The suppression is a one-line, localised
annotation on a single overload; it is the correct tool here. The same pattern appears in
typeshed itself for collection types that specialise return types in subclasses.

---

## Updated `__await__` in Manager

`Manager` delegates through `QuerySet`, so no change is needed in `Manager`. All Manager
methods that return `QuerySet[M]` (`.filter()`, `.all()`, etc.) are correct as-is; the
user must `await` the resulting `QuerySet` to get `EvaluatedQuerySet[M]`.

```python
# ── QuerySet ─────────────────────────────────────────────────────────────

class QuerySet[M]:
    """Lazy, chainable async query builder.

    Queries are not executed until the queryset is awaited or async-iterated.
    Awaiting produces an ``EvaluatedQuerySet[M]`` with rows cached — see that
    class for synchronous indexing, ``len()``, and iteration.

    Examples::

        # Chain, then await
        qs = Author.objects.filter(active=True).order_by("-created_at")
        results = await qs             # EvaluatedQuerySet[Author]
        results[0].name                # str — direct, no await

        # Async iteration (streams without materialising all rows)
        async for author in Author.objects.order_by("name"):
            print(author.name)

        # Await a single object
        author = await Author.objects.get(pk=1)   # Author
    """

    # ── Filtering ─────────────────────────────────────────────────────────
    def filter(self, *args: Q, **kwargs: Any) -> QuerySet[M]: ...
    def exclude(self, *args: Q, **kwargs: Any) -> QuerySet[M]: ...
    def all(self) -> QuerySet[M]: ...
    def none(self) -> QuerySet[M]: ...

    # ── Ordering / dedup ──────────────────────────────────────────────────
    def order_by(self, *fields: str) -> QuerySet[M]: ...
    def reverse(self) -> QuerySet[M]: ...
    def distinct(self, *fields: str) -> QuerySet[M]: ...

    # ── Traversal ─────────────────────────────────────────────────────────
    def select_related(self, *fields: str, depth: int | None = None) -> QuerySet[M]: ...
    def prefetch_related(self, *lookups: str) -> QuerySet[M]: ...
    def only(self, *fields: str) -> QuerySet[M]: ...
    def defer(self, *fields: str) -> QuerySet[M]: ...

    # ── Routing ───────────────────────────────────────────────────────────
    def using(self, alias: str) -> QuerySet[M]: ...
    def using_transaction(self, txn: Transaction) -> QuerySet[M]: ...

    # ── Annotation / projection ───────────────────────────────────────────
    def annotate(self, **kwargs: Any) -> QuerySet[M]: ...
    def values(self, *fields: str) -> QuerySet[dict[str, Any]]: ...

    @overload
    def values_list(self, *fields: str, flat: Literal[True]) -> QuerySet[Any]: ...
    @overload
    def values_list(self, *fields: str, flat: Literal[False] = ...) -> QuerySet[tuple[Any, ...]]: ...
    @overload
    def values_list(self, *fields: str, flat: bool = ...) -> QuerySet[tuple[Any, ...]] | QuerySet[Any]: ...

    # ── Async protocol ────────────────────────────────────────────────────
    def __aiter__(self) -> AsyncIterator[M]: ...

    # Awaiting fetches all rows and returns an EvaluatedQuerySet (rows cached).
    def __await__(self) -> Generator[Any, None, EvaluatedQuerySet[M]]: ...

    def iterator(self, chunk_size: int = 2000) -> AsyncIterator[M]: ...

    # ── Slicing ───────────────────────────────────────────────────────────
    # Integer index on an *unevaluated* queryset is an async DB fetch.
    # On an *evaluated* queryset use EvaluatedQuerySet.__getitem__ (returns M).
    @overload
    def __getitem__(self, key: int) -> Coroutine[Any, Any, M]: ...
    @overload
    def __getitem__(self, key: slice) -> QuerySet[M]: ...

    # ── Terminal async ────────────────────────────────────────────────────
    def get(self, *args: Q, **kwargs: Any) -> Coroutine[Any, Any, M]: ...
    def create(self, **kwargs: Any) -> Coroutine[Any, Any, M]: ...
    def get_or_create(
        self,
        defaults: dict[str, Any] | None = None,
        **kwargs: Any,
    ) -> Coroutine[Any, Any, tuple[M, bool]]: ...
    def update_or_create(
        self,
        defaults: dict[str, Any] | None = None,
        **kwargs: Any,
    ) -> Coroutine[Any, Any, tuple[M, bool]]: ...
    def update(self, **kwargs: Any) -> Coroutine[Any, Any, int]: ...
    def delete(self) -> Coroutine[Any, Any, tuple[int, dict[str, int]]]: ...
    def count(self) -> Coroutine[Any, Any, int]: ...
    def exists(self) -> Coroutine[Any, Any, bool]: ...
    def first(self) -> Coroutine[Any, Any, M | None]: ...
    def last(self) -> Coroutine[Any, Any, M | None]: ...
    def earliest(self, *fields: str) -> Coroutine[Any, Any, M]: ...
    def latest(self, *fields: str) -> Coroutine[Any, Any, M]: ...
    def aggregate(self, **kwargs: Any) -> Coroutine[Any, Any, dict[str, Any]]: ...
    def bulk_create(
        self,
        objs: list[M],
        batch_size: int | None = None,
        ignore_conflicts: bool = False,
    ) -> Coroutine[Any, Any, list[M]]: ...
    def bulk_update(
        self,
        objs: list[M],
        fields: list[str],
        batch_size: int | None = None,
    ) -> Coroutine[Any, Any, int]: ...
    def raw(
        self,
        sql: LiteralString,
        params: list[Any] | None = None,
    ) -> RawQuerySet[M]: ...


# ── EvaluatedQuerySet ─────────────────────────────────────────────────────

class EvaluatedQuerySet[M](QuerySet[M]):
    """QuerySet with rows fetched from the database and held in an internal cache.

    Returned by ``await qs``.  Supports synchronous access patterns identical
    to Django's queryset API:

    - ``results[0]``          →  ``M``       (no ``await`` needed)
    - ``results[0:3]``        →  ``EvaluatedQuerySet[M]``
    - ``len(results)``        →  ``int``
    - ``for r in results``    →  ``M``
    - ``bool(results)``       →  ``bool``
    - ``r in results``        →  ``bool``
    - ``results.filter(...)`` →  ``QuerySet[M]``  (new unevaluated queryset)

    Full example::

        results = await Author.objects.filter(name="Alice")
        assert len(results) == 1
        assert results[0].name == "Alice"          # direct attribute access

        # Still chainable — re-filtering starts a new DB round-trip
        active = await results.filter(active=True)
        assert len(active) <= len(results)
    """

    # Override __getitem__: integer access is synchronous on an evaluated queryset.
    # The parent (QuerySet) has __getitem__(int) -> Coroutine[Any, Any, M];
    # the override here narrows the return to M.
    # type: ignore[override] suppresses the Liskov check for this specific case —
    # the override is safe because after evaluation no async fetch is needed.
    @overload  # type: ignore[override]
    def __getitem__(self, key: int) -> M: ...
    @overload
    def __getitem__(self, key: slice) -> EvaluatedQuerySet[M]: ...

    # ── Synchronous collection protocol ──────────────────────────────────
    def __iter__(self)               -> Iterator[M]: ...
    def __len__(self)                -> int: ...
    def __bool__(self)               -> bool: ...
    def __contains__(self, item: object) -> bool: ...
    def __reversed__(self)           -> Iterator[M]: ...
```

## Behaviour matrix

```python
# ── Unevaluated QuerySet[Author] ─────────────────────────────────────────
qs = Author.objects.filter(active=True)        # QuerySet[Author]
qs.filter(age__gte=18)                         # QuerySet[Author]   — chain  ✓
await qs[0]                                    # Author             — async  ✓
await qs.get(pk=1)                             # Author             — async  ✓
async for r in qs: ...                         # Author             — async  ✓

# ── EvaluatedQuerySet[Author] (post-await) ───────────────────────────────
results = await qs                             # EvaluatedQuerySet[Author]
results[0]                                     # Author             — sync   ✓
results[0].name                                # str                — attr   ✓
results[0:3]                                   # EvaluatedQuerySet[Author]  ✓
len(results)                                   # int                         ✓
for r in results: ...                          # Author                      ✓
bool(results)                                  # bool                        ✓
author in results                              # bool                        ✓
results.filter(age=25)                         # QuerySet[Author]  — re-query ✓
await results.filter(age=25)                   # EvaluatedQuerySet[Author]   ✓
await results.get(pk=1)                        # Author             — async  ✓
await results.count()                          # int                — async  ✓
```
