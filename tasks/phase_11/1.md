# Task 11.1 — Remove Django-Specific Cruft (`help_text`, `blank`, `app_label`, `app_name`)

## Objective

Strip `help_text`, `blank`, `app_label`, and `app_name` from every layer of the codebase:
Rust structs, PyO3 keyword arguments, Python stubs, test fixtures, and documentation.
These are Django application-framework concepts that add complexity without providing value
in a standalone ORM.

## Affected Locations

| Layer | File | Change |
|-------|------|--------|
| Rust core | `ormpi-core/src/fields.rs` | Remove `help_text: String` and `blank: bool` from `FieldDef` |
| Rust core | `ormpi-core/src/models.rs` | Remove `app_label: Option<String>` and `app_name: Option<String>` from `ModelMeta` |
| PyO3 bindings | `ormpi-py/src/fields.rs` | Remove `help_text` and `blank` kwargs from all `impl_field_class!` expansions |
| PyO3 bindings | `ormpi-py/src/models.rs` | Remove `app_label` / `app_name` parsing from `Meta` inner class |
| Stubs | `python/ormpi/fields.pyi` | Remove `help_text` and `blank` parameters from all field stubs |
| Stubs | `python/ormpi/models.pyi` | Remove `app_label` / `app_name` from `Meta` stub |
| Tests | `tests/conftest.py` | Remove `app_label = "test"` from all `class Meta` blocks |
| Stubs | `python/ormpi/__init__.pyi` | Remove from `__all__` if exported |

```rust

// AFTER
```
```rust
#[pyo3(signature = (
    *,
    null = false,
    unique = false,
    primary_key = false,
    db_index = false,
    db_column = None,
    default = None,
    editable = true,
```

## PyO3: `Meta` Class Parsing — Remove `app_label` / `app_name`

```rust
// ormpi-py/src/models.rs  — parse_meta() function
fn parse_meta(py: Python<'_>, cls: &PyAny) -> PyResult<ModelMeta> {
    let meta = match cls.getattr("Meta") {
        Ok(m) => m,
        Err(_) => return Ok(ModelMeta::default()),
    };

    let db_table = meta.getattr("db_table").ok()
        .and_then(|v| v.extract::<String>().ok());

    let ordering: Vec<String> = meta.getattr("ordering").ok()
        .and_then(|v| v.extract().ok())
        .unwrap_or_default();

    let managed: bool = meta.getattr("managed").ok()
        .and_then(|v| v.extract().ok())
        .unwrap_or(true);

    // Do NOT read app_label or app_name — removed.

    Ok(ModelMeta { db_table, ordering, managed, ..Default::default() })
}
```

If existing code reads `meta.app_label` anywhere (e.g. for generating table names or
migration keys), replace it with the model's class name snake-cased, or with `db_table`
if explicitly set.

**Default table name rule** (unchanged from phase 3, now the only rule):
```rust
pub fn default_table_name(class_name: &str) -> String {
    // PascalCase → snake_case, e.g. "ArticleComment" → "article_comment"
    let mut out = String::new();
    for (i, ch) in class_name.chars().enumerate() {
        if ch.is_uppercase() && i > 0 { out.push('_'); }
        out.push(ch.to_lowercase().next().unwrap());
    }
    out
}
```
