# Task 11.3 — Instance Attribute Population from DB Rows

## Objective

Ensure the full round-trip works correctly:

1. **Write path** — `instance.title = "Hello"` calls the field descriptor's `__set__`, which writes to `instance._ormpi_values["title"]` and marks `"title"` in `instance._ormpi_dirty`.
2. **Read path** — `instance.title` calls the field descriptor's `__get__`, which reads from `instance._ormpi_values["title"]`.
3. **Hydration path** — When `evaluate()` fetches rows from the database, `rows_to_model_instances()` must populate `instance._ormpi_values` from the DB row so that the descriptors have data to return.

Without step 3, `author = await Author.objects.get(pk=1)` produces an instance where `author.name` returns `None` even though the data was fetched successfully.

---

## Data Model on the Python Instance

Every `Model` instance carries two dicts and one set, all stored as plain Python attributes (not exposed in the public API):

```
instance.__dict__ = {
    "_ormpi_values": {"id": 1, "name": "Alice", "email": "alice@test.com", "age": None, "active": True},
    "_ormpi_dirty":  set(),     # field names changed since last save/load
    "_ormpi_state":  {"adding": False, "db": "default"},
}
```

These are initialized in `__init__` (for new instances) and in `rows_to_model_instances()` (for DB-fetched instances).

## Rust: Field Descriptor `__get__` / `__set__`

The descriptor is implemented on each `Py<FieldClass>` object that was attached to the
model class via `contribute_to_class()`.

```rust
// ormpi-py/src/fields.rs

// Descriptor protocol — called by Python when accessing `instance.title`
#[pymethods]
impl PyFieldDescriptor {
    /// instance.field_name  — returns value from _ormpi_values
    fn __get__<'py>(
        &self,
        py: Python<'py>,
        obj: Option<&PyAny>,
        _objtype: Option<&PyAny>,
    ) -> PyResult<PyObject> {
        match obj {
            // Accessed on the class itself, not an instance → return the descriptor
            None => Ok(self.into_py(py)),
            Some(instance) => {
                let values = instance
                    .getattr("_ormpi_values")?
                    .downcast::<PyDict>()?;

                match values.get_item(&self.attname)? {
                    Some(val) => Ok(val.into_py(py)),
                    None      => Ok(py.None()),
                }
            }
        }
    }

    /// instance.field_name = value  — writes to _ormpi_values, marks dirty
    fn __set__(
        &self,
        instance: &PyAny,
        value: PyObject,
    ) -> PyResult<()> {
        // Write the value
        let values = instance
            .getattr("_ormpi_values")?
            .downcast::<PyDict>()?;
        values.set_item(&self.attname, &value)?;

        // Mark dirty (only if instance is not in the "adding" state,
        // i.e. it came from the DB)
        let state = instance
            .getattr("_ormpi_state")?
            .downcast::<PyDict>()?;

        let adding: bool = state
            .get_item("adding")?
            .map(|v| v.extract().unwrap_or(true))
            .unwrap_or(true);

        if !adding {
            let dirty = instance
                .getattr("_ormpi_dirty")?
                .downcast::<PySet>()?;
            dirty.add(self.attname.as_str())?;
        }

        Ok(())
    }
}
```

**Important**: When `adding = true` (a brand-new unsaved instance), every field assignment
is a normal initialization — we do NOT mark the field dirty since `save()` will do a full
INSERT using all `_ormpi_values` keys anyway.

## Rust: `PyModel.__init__` — Initialize Value Dict

```rust
// ormpi-py/src/models.rs

#[pymethods]
impl PyModel {
    /// Called when user writes `author = Author(name="Alice", email="a@test.com")`
    #[new]
    #[pyo3(signature = (**kwargs))]
    fn new(py: Python<'_>, kwargs: Option<&PyDict>) -> PyResult<Self> {
        let instance = PyModel {
            // ... internal fields
        };
        Ok(instance)
    }

    /// __init__ is called after __new__ with kwargs
    #[pyo3(signature = (**kwargs))]
    fn __init__(slf: PyRef<'_, Self>, py: Python<'_>, kwargs: Option<&PyDict>) -> PyResult<()> {
        let inst = slf.as_ref();

        // 1. Initialize _ormpi_values with field defaults
        let values = PyDict::new(py);
        let model_def = get_model_def(inst.get_type().name()?)?;
        for field in &model_def.fields {
            let default = field.default.as_ref()
                .map(|d| d.to_py(py))
                .transpose()?
                .unwrap_or_else(|| py.None());
            values.set_item(&field.attname, default)?;
        }

        // 2. Apply kwargs
        if let Some(kw) = kwargs {
            for (k, v) in kw.iter() {
                let key: String = k.extract()?;
                // Validate it's a real field name
                if model_def.fields.iter().any(|f| f.attname == key) {
                    values.set_item(&key, v)?;
                } else {
                    return Err(PyTypeError::new_err(format!(
                        "{} got unexpected keyword argument '{}'",
                        model_def.name, key
                    )));
                }
            }
        }

        // 3. Set instance attributes
        inst.setattr("_ormpi_values", values)?;
        inst.setattr("_ormpi_dirty",  PySet::empty(py)?)?;
        inst.setattr("_ormpi_state",  {
            let s = PyDict::new(py);
            s.set_item("adding", true)?;
            s.set_item("db",     "default")?;
            s
        })?;

        Ok(())
    }
}
```

## Rust: `rows_to_model_instances()` — Hydrate from DB Row

This function converts a `Vec<OrmpiRow>` (the raw DB result) into a list of Python
`Model` instances with `_ormpi_values` fully populated.

```rust
// ormpi-py/src/query.rs

pub fn rows_to_model_instances<'py>(
    py: Python<'py>,
    model_cls: &PyType,
    rows: &[OrmpiRow],
    model_def: &ModelDef,
) -> PyResult<Vec<PyObject>> {
    let mut instances = Vec::with_capacity(rows.len());

    for row in rows {
        // 1. Create instance WITHOUT calling __init__ (we supply values directly)
        //    Use object.__new__(ModelClass) to skip __init__
        let builtins = py.import("builtins")?;
        let object_cls = builtins.getattr("object")?;
        let inst = object_cls
            .getattr("__new__")?
            .call1((model_cls,))?;

        // 2. Build _ormpi_values from DB row
        let values = PyDict::new(py);
        for field in &model_def.fields {
            let col = field.db_column();
            let py_val = row.get_as_py(py, &col)?;
            values.set_item(&field.attname, py_val)?;
        }

        // 3. Set instance state — not "adding" since it came from DB
        let state = PyDict::new(py);
        state.set_item("adding", false)?;
        state.set_item("db", "default")?;   // TODO: use actual db alias from QueryState

        inst.setattr("_ormpi_values", values)?;
        inst.setattr("_ormpi_dirty",  PySet::empty(py)?)?;
        inst.setattr("_ormpi_state",  state)?;

        instances.push(inst.into_py(py));
    }

    Ok(instances)
}
```

### `OrmpiRow::get_as_py()` — Value Coercion

The `OrmpiRow` already carries `Vec<(String, OrmpiValue)>`. The `get_as_py()` helper
finds the column by name and converts the `OrmpiValue` to Python:

```rust
// ormpi-core/src/row.rs

impl OrmpiRow {
    pub fn get_as_py<'py>(&self, py: Python<'py>, column: &str) -> PyResult<PyObject> {
        let val = self.columns.iter()
            .find(|(name, _)| name == column)
            .map(|(_, v)| v)
            .unwrap_or(&OrmpiValue::Null);

        value_to_py(py, val)
    }
}

pub fn value_to_py(py: Python<'_>, val: &OrmpiValue) -> PyResult<PyObject> {
    Ok(match val {
        OrmpiValue::Null             => py.None(),
        OrmpiValue::Bool(b)          => b.into_py(py),
        OrmpiValue::Int(i)           => i.into_py(py),
        OrmpiValue::BigInt(i)        => i.into_py(py),
        OrmpiValue::Float(f)         => f.into_py(py),
        OrmpiValue::Text(s)          => s.into_py(py),
        OrmpiValue::Bytes(b)         => PyBytes::new(py, b).into_py(py),
        OrmpiValue::Decimal(d)       => {
            // Convert to Python decimal.Decimal
            let decimal_mod = py.import("decimal")?;
            decimal_mod.getattr("Decimal")?.call1((d.to_string(),))?.into_py(py)
        }
        OrmpiValue::Uuid(u)          => {
            let uuid_mod = py.import("uuid")?;
            uuid_mod.getattr("UUID")?.call1((u.to_string(),))?.into_py(py)
        }
        OrmpiValue::Json(j)          => {
            let json_mod = py.import("json")?;
            json_mod.getattr("loads")?.call1((j.to_string(),))?.into_py(py)
        }
        OrmpiValue::Date(d)          => {
            // chrono::NaiveDate → Python datetime.date
            let dt_mod = py.import("datetime")?;
            dt_mod.getattr("date")?.call1((d.year(), d.month(), d.day()))?.into_py(py)
        }
        OrmpiValue::DateTime(dt)     => {
            // chrono::NaiveDateTime → Python datetime.datetime (UTC)
            let dt_mod = py.import("datetime")?;
            let timezone = dt_mod.getattr("timezone")?.getattr("utc")?;
            dt_mod.getattr("datetime")?.call(
                (dt.year(), dt.month(), dt.day(),
                 dt.hour(), dt.minute(), dt.second(), dt.timestamp_subsec_micros()),
                Some([("tzinfo", timezone)].into_py_dict(py)),
            )?.into_py(py)
        }
    })
}
```

## Instance `pk` Property

The `pk` property must resolve to whatever field has `primary_key=True`:

```rust
// ormpi-py/src/models.rs

#[pymethods]
impl PyModel {
    #[getter]
    fn pk(&self, py: Python<'_>, slf: PyRef<'_,Self>) -> PyResult<PyObject> {
        let model_def = get_model_def(slf.as_ref().get_type().name()?)?;
        let pk_field = model_def.fields.iter()
            .find(|f| f.primary_key)
            .ok_or_else(|| PyValueError::new_err("Model has no primary key"))?;

        let values = slf.as_ref().getattr("_ormpi_values")?;
        let values = values.downcast::<PyDict>()?;
        Ok(values.get_item(&pk_field.attname)?
            .map(|v| v.into_py(py))
            .unwrap_or_else(|| py.None()))
    }

    #[setter]
    fn set_pk(&self, slf: PyRef<'_, Self>, value: PyObject) -> PyResult<()> {
        let model_def = get_model_def(slf.as_ref().get_type().name()?)?;
        let pk_field = model_def.fields.iter()
            .find(|f| f.primary_key)
            .ok_or_else(|| PyValueError::new_err("Model has no primary key"))?;

        let values = slf.as_ref().getattr("_ormpi_values")?;
        let values = values.downcast::<PyDict>()?;
        values.set_item(&pk_field.attname, value)?;
        Ok(())
    }
}
```

## `save()` — Read from `_ormpi_values`

The `save_instance()` function must read field values from `_ormpi_values`, not from
instance attributes directly:

```rust
// ormpi-py/src/models.rs

async fn save_instance(
    py: Python<'_>,
    inst: &PyAny,
    model_def: &ModelDef,
    pool: &OrmpiPool,
    backend: DatabaseBackend,
) -> crate::Result<()> {
    let values: &PyDict = inst.getattr("_ormpi_values")?.downcast()?;
    let state:  &PyDict = inst.getattr("_ormpi_state")?.downcast()?;
    let dirty:  &PySet  = inst.getattr("_ormpi_dirty")?.downcast()?;

    let adding: bool = state.get_item("adding")?
        .and_then(|v| v.extract().ok())
        .unwrap_or(true);

    if adding {
        // INSERT — use all non-auto-increment fields
        let mut fields_vals: Vec<(String, OrmpiValue)> = Vec::new();
        for field in &model_def.fields {
            if field.auto_increment { continue; }  // skip auto PK on INSERT
            let py_val = values.get_item(&field.attname)?
                .unwrap_or_else(|| py.None());
            fields_vals.push((field.db_column(), py_to_value(py, py_val, &field.field_type)?));
        }
        let pk = execute_insert(pool, backend, &model_def.table_name(), fields_vals).await?;
        // Write back the generated PK
        let pk_field = model_def.pk_field().expect("pk field missing");
        values.set_item(&pk_field.attname, pk.into_py(py))?;
        state.set_item("adding", false)?;
    } else {
        // UPDATE — only dirty fields
        let dirty_names: Vec<String> = dirty.iter()
            .map(|v| v.extract::<String>())
            .collect::<PyResult<_>>()?;

        if dirty_names.is_empty() { return Ok(()); }

        let mut fields_vals: Vec<(String, OrmpiValue)> = Vec::new();
        for name in &dirty_names {
            let field = model_def.field_by_attname(name).ok_or_else(|| {
                OrmpiError::field(format!("Unknown field: {}", name))
            })?;
            let py_val = values.get_item(name)?.unwrap_or_else(|| py.None());
            fields_vals.push((field.db_column(), py_to_value(py, py_val, &field.field_type)?));
        }

        let pk_field = model_def.pk_field().expect("pk field missing");
        let pk_val = values.get_item(&pk_field.attname)?
            .ok_or_else(|| OrmpiError::integrity("Instance has no PK value"))?;
        let pk_ormpi = py_to_value(py, pk_val, &pk_field.field_type)?;

        execute_update(pool, backend, &model_def.table_name(), fields_vals, pk_ormpi).await?;
        // Clear dirty set after successful save
        dirty.clear()?;
    }

    Ok(())
}
```

## End-to-End Test

```python
# tests/unit/test_instance_values.py

async def test_descriptor_read_write(db):
    author = Author(name="Alice", email="alice@test.com")
    assert author.name == "Alice"       # __get__ reads from _ormpi_values
    assert author.pk is None            # not saved yet

    author.name = "Bob"
    assert author.name == "Bob"
    assert author._ormpi_dirty == set() # still "adding", dirty not tracked

async def test_fetched_instance_has_values(db):
    created = await Author.objects.create(name="Carol", email="carol@test.com", age=28)
    pk = created.pk
    assert pk is not None

    fetched = await Author.objects.get(pk=pk)
    assert fetched.name == "Carol"        # hydrated from DB row
    assert fetched.email == "carol@test.com"
    assert fetched.age == 28
    assert fetched._ormpi_state["adding"] is False

async def test_dirty_tracking_after_fetch(db):
    author = await Author.objects.create(name="Dave", email="dave@test.com")
    fetched = await Author.objects.get(pk=author.pk)

    fetched.name = "David"
    assert "name" in fetched._ormpi_dirty
    assert "email" not in fetched._ormpi_dirty

async def test_save_only_updates_dirty(db, monkeypatch):
    author = await Author.objects.create(name="Eve", email="eve@test.com", age=30)
    fetched = await Author.objects.get(pk=author.pk)

    sql_calls = []
    # ... monkeypatch to capture SQL ...
    fetched.name = "Evelyn"
    await fetched.save()

    # Only the name column should appear in the UPDATE statement
    update_sql = next(s for s in sql_calls if "UPDATE" in s.upper())
    assert "name" in update_sql
    assert "age"  not in update_sql
    assert "email" not in update_sql

async def test_save_new_writes_pk_back(db):
    author = Author(name="Frank", email="frank@test.com")
    assert author.pk is None
    await author.save()
    assert author.pk is not None
    assert isinstance(author.pk, int)
    assert author._ormpi_state["adding"] is False
```

## Acceptance Criteria

- [x] `Author(name="Alice").name == "Alice"` (descriptor `__get__` returns value from `_ormpi_values`)
- [x] `author.name = "Bob"` writes to `_ormpi_values`
- [x] After `Author.objects.get(pk=1)`, all field attributes return correct DB values
- [x] `_ormpi_state["adding"]` is `False` for DB-fetched instances
- [x] `_ormpi_dirty` is populated only for fields changed after a fetch
- [x] `save()` on an updated instance emits `UPDATE` with only dirty columns
- [x] `save()` on a new instance writes the generated PK back to `instance.pk`
- [x] `author.pk` resolves to whatever field has `primary_key=True`
